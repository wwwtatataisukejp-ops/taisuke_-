# 商材・販路戦略（運転資金 ¥500,000 ／ 目標ROI 50%）

> 作成: 2026/07/27 ／ 議長: `kpi-analyst`
> 招集: `niche-hunter`（商材）`platform-optimizer`（販路）`cashflow-planner`（資金配分）
> 参照: `00-sedori-basics.md` `01-sourcing-playbook.md` `02-pricing-and-roi.md` `05-platform-rules.md`

---

## 【結論】

```
主軸カテゴリ : 型番で特定でき、状態で価格が大きく動き、真贋リスクが低い中古実用品
推奨単価帯   : 想定売価 ¥12,000〜25,000
同時保有点数 : 25〜35点
仕入の絶対条件: 想定売価の 57%以下 で仕入れられること
主戦場       : ヤフオク!（相場が立つ物）＋ メルカリ（回転させる物）の2本
Amazonの相乗り: 当面やらない（ROI50%が構造的に取れない）
```

**ROI50%は、CLAUDE.md の基準（30%）の1.67倍です。**
これは「良い商品を探す」のではなく「**99%を見送る**」ことで達成されます。
仕入点数は減り、リサーチ時間は増えます。そのコストを受け入れる前提の設計です。

## 1. ROI50%が要求する条件（先に数式で確定させる）

### 1.1 上限仕入値の公式

```
上限仕入値 = (想定売価 × (1 − 手数料率) − 出荷送料 − 梱包材費) ÷ 1.5
```

### 1.2 単価帯別の上限仕入値
> 前提：手数料率10%・梱包材費¥100・送料は下記想定（**手数料と送料は公式で要検証**）

| 想定売価 | 送料想定 | **上限仕入値** | 売価に対する比率 | 粗利 | 粗利率 |
|---|---|---|---|---|---|
| ¥3,000 | ¥600 | ¥1,333 | **44.4%** | ¥667 | 22.2% |
| ¥5,000 | ¥600 | ¥2,533 | **50.7%** | ¥1,267 | 25.3% |
| ¥8,000 | ¥600 | ¥4,333 | **54.2%** | ¥2,167 | 27.1% |
| ¥12,000 | ¥700 | ¥6,667 | **55.6%** | ¥3,333 | 27.8% |
| ¥15,000 | ¥700 | ¥8,533 | **56.9%** | ¥4,267 | 28.4% |
| ¥20,000 | ¥800 | ¥11,467 | **57.3%** | ¥5,733 | 28.7% |
| ¥25,000 | ¥800 | ¥14,467 | **57.9%** | ¥7,233 | 28.9% |

### 1.3 この表から読み取れる3つの事実

**① 低単価はROI50%に構造的に向かない**
¥3,000の商品は、売価の44%（¥1,333以下）で仕入れないとROI50%になりません。
送料と手数料という固定費の比率が高すぎるためです。
**¥5,000未満の商品は、この戦略から除外します。**

**② ¥12,000以上で仕入率が安定する**
売価¥12,000を超えると、必要な仕入率が56〜58%で頭打ちになります。
つまり「**売価の6割以下で買えるか**」が唯一の判断基準になります。

**③ ROI50%は粗利率28%前後を意味する**
粗利率の基準（20%）は自動的にクリアします。ROI50%を追えば、粗利率は付いてきます。

### 1.4 現場で使う唯一のルール

```
想定売価 × 0.57 ＝ 上限仕入値
これを1円でも超えたら買わない。
```

例：相場¥18,000の商品 → **¥10,260以下でしか買わない**

## 2. 資金設計（¥500,000をどう配分するか）

### 2.1 配分の原則

| 区分 | 金額 | 用途 |
|---|---|---|
| 在庫に回す上限 | **¥350,000** | 在庫比率70%の上限（`00-sedori-basics.md`） |
| 現金でキープ | **¥150,000** | 返品対応・仕入機会・生活防衛 |

**この¥150,000には手を付けません。** これを崩した時点で、
CLAUDE.md 6.4 の赤線6（資金の90%以上を在庫に変える）に近づきます。

### 2.2 到達する利益の試算

```
月間粗利 = 在庫投下額 × ROI × (30 ÷ 回転日数)
```

| シナリオ | 在庫投下 | ROI | 回転 | 月間粗利 |
|---|---|---|---|---|
| 保守（基準ライン） | ¥350,000 | 50% | 60日 | ¥87,500 |
| **標準（目標）** | **¥350,000** | **50%** | **45日** | **¥116,667** |
| 好調 | ¥350,000 | 50% | 30日 | ¥175,000 |

**ROI50%を狙うと、回転は伸びる傾向にあります。**
厳選するほど商品はニッチになり、買い手が見つかるまでの時間が延びるためです。
したがって**現実的な目標は「ROI50% × 回転45日 → 月粗利 約¥117,000」**とします。

### 2.3 点数と単価の関係

| 主軸単価（売価） | 平均仕入値 | 同時保有点数 | 月間販売点数（回転45日） |
|---|---|---|---|
| ¥8,000 | ¥4,300 | 81点 | 54点 ← **作業量が破綻** |
| ¥12,000 | ¥6,700 | 52点 | 35点 |
| **¥18,000** | **¥10,300** | **34点** | **23点** ← 推奨 |
| ¥25,000 | ¥14,500 | 24点 | 16点 |

**単価¥15,000〜25,000 が、1人で回せる作業量の適正解**です。
低単価にすると、同じ利益を出すのに3倍の点数を検品・出品・梱包することになります。
CLAUDE.md の時間制約に反します。

## 3. 何を売るか（商材の選定）

### 3.1 ROI50%が取れる商材の条件

「安く買える商品」ではなく、「**売り手が値付けを間違える構造がある商品**」を狙います。

| 条件 | 理由 |
|---|---|
| ① **型番で相場が確認できる** | 相場が読めない商品は、ROI50%かどうか判断できない |
| ② **状態で価格が2倍以上動く** | 状態の目利き＝利益の源泉になる |
| ③ **真贋リスクが低い** | ブランド品の真贋グレーは赤線1。初期は触らない |
| ④ **出品者が少ない（3人以下）** | 価格競争が起きるとROI50%は消える |
| ⑤ **売り手が素人（個人・一般店舗）** | 情報差が残っている |
| ⑥ **単価 ¥12,000〜25,000** | 上記1.3の②③より |

### 3.2 候補カテゴリの評価

> **重要：以下は「構造的にROI50%が成立しやすい仮説」です。**
> 実際の相場・出品者数は未検証です。着手前に必ず `demand-forecaster` と
> `competitor-analyst` が実データで検証してください（`01-sourcing-playbook.md` 第2章）。

| カテゴリ | ①型番 | ②状態差 | ③真贋 | ④競合 | ⑤情報差 | ⑥単価 | 総合 |
|---|---|---|---|---|---|---|---|
| **電動工具（プロ向け）** | ◎ | ◎ | ○ | ○ | ◎ | ◎ | **◎ 推奨** |
| **中古オーディオ機器** | ◎ | ◎ | ○ | ○ | ○ | ◎ | **◎ 推奨** |
| **アウトドア用品（定価維持ブランド）** | ○ | ○ | △ | △ | ○ | ◎ | ○ |
| 中古カメラ・レンズ | ◎ | ◎ | ○ | △ | ○ | ◎ | ○（検品難度高） |
| 楽器・音響機材 | ◎ | ◎ | ○ | ◎ | ○ | ◎ | ○（知識要） |
| ゲーム・ホビー | ○ | ○ | △ | × | △ | △ | △ |
| ブランド衣類・バッグ | △ | ○ | **×** | × | ○ | ○ | **× 初期は不可** |
| PC周辺機器・パーツ | ◎ | △ | ○ | × | △ | △ | △（相場下落が速い） |

### 3.3 推奨する2カテゴリと、その理由

#### 第1候補：**電動工具（プロ向けブランドの中古）**

| 項目 | 内容 |
|---|---|
| なぜROI50%が取れるか | 一般のリサイクル店は工具の型番・年式による価格差を把握していない。プロ向け機種と DIY 機種の相場差が大きいのに、同じ棚に同じ値札で並ぶ |
| 単価帯 | ¥10,000〜30,000（本体・セット品） |
| 目利きのポイント | 型番の世代、バッテリー規格、付属品（バッテリー・充電器の有無で価格が倍変わる） |
| 真贋リスク | 低い（模倣品は存在するが、正規流通品との判別が比較的容易） |
| 買い手 | 職人・個人事業主。**必要だから買う**ので値引き交渉が少なく、回転が読める |
| 注意点 | バッテリーの劣化・膨張チェックが必須（`03-product-inspection.md` 5.3） |

#### 第2候補：**中古オーディオ機器（ヘッドホン・アンプ・スピーカー）**

| 項目 | 内容 |
|---|---|
| なぜROI50%が取れるか | 型番ごとに評価が固まっており相場が明確。一方で「古いオーディオ＝安い」と誤認して手放す個人が多い |
| 単価帯 | ¥12,000〜25,000 |
| 目利きのポイント | 型番の評価、動作確認の範囲、イヤーパッド等の消耗品状態 |
| 真贋リスク | 低い |
| 買い手 | 趣味層。相場を知っているため、**状態の正確な記載が価格に直結**する |
| 注意点 | 通電・音出し確認が必須。PSE表示の確認（`07-legal-compliance.md` 4.2） |

### 3.4 初期に手を出さないもの（明確に捨てる）

| 対象 | 理由 |
|---|---|
| ブランドバッグ・財布・時計 | **真贋リスク。赤線1に抵触する可能性が最も高い** |
| ¥5,000未満の商品 | ROI50%が構造的に成立しない（1.3①） |
| 新品の相乗り（Amazon） | 価格競争でROI50%が維持できない |
| チケット・酒類・医薬品・化粧品 | 許可・法令（`07-legal-compliance.md` 第4章） |
| 海外仕入 | リードタイムで回転基準を超える。資金50万では拘束が重すぎる |
| 大型・重量物 | 送料が上限仕入値を圧迫する（1.2の表参照） |

## 4. どこで売るか（販路設計）

### 4.1 販路の役割分担

```
ヤフオク!  … 相場を知る買い手に、正確な状態記載で「適正価格」で売る
メルカリ   … 一般層に、早く回す
Amazon     … 当面使わない
eBay       … 当面使わない
```

### 4.2 販路別の評価

| 販路 | ROI50%との相性 | 理由 |
|---|---|---|
| **ヤフオク!** | **◎** | 専門性の高い中古（工具・オーディオ）の買い手が集まる。状態記載の精度が価格に反映される。個人出品者の値付けブレ＝情報差が残っている |
| **メルカリ** | **○** | 回転が速い。ただし値下げ交渉前提のため、初期価格に交渉余地を織り込む必要がある |
| Amazon | **×**（当面） | 相乗りは価格競争でROI50%が維持できない。中古も出品者が多いカテゴリでは同じ |
| eBay | ×（当面） | 返品時の国際送料と長いリードタイムが、資金50万の規模に見合わない |

### 4.3 出す順番のルール

```
① まずヤフオク!に、相場価格（＝ROI50%が取れる価格）で出す
② 30日で売れなければ、メルカリへ移す（`platform-optimizer` が出品文を作り直す）
③ 45日で売れなければ、値下げ（`repricing-operator`）
④ 60日で損益分岐まで許容、90日で損切り判断
```

**販路を移すときは、出品文を必ず作り直します。**
コピペは文字数超過・禁止表現・他販路名の残存という規約事故になります（`05-platform-rules.md` 5.1）。

## 5. どうやって売るか（オペレーション）

### 5.1 ROI50%を守る仕入オペレーション

現場での判断は、この4ステップだけです（1商品90秒）。

```
① 型番を特定する          → できなければ買わない
② 直近30日の売却実績を見る → 実績3件以下なら買わない
③ 出品者数を数える        → 8人以上なら買わない
④ 相場 × 0.57 を計算する  → 値札がこれを超えたら買わない
```

**④で「惜しい」と思ったものを買うのが、ROI50%が崩れる唯一の原因です。**
ROI30%の商品を買ってしまうと、それが資金を45日間占有し、
その間にROI50%の商品を買う資金がなくなります。

### 5.2 回転を守る出品オペレーション

| 工程 | 期限 | 担当 |
|---|---|---|
| 仕入 → 検品 | 当日〜翌日 | `condition-grader` |
| 検品 → 撮影 | 翌日 | `photo-director` |
| 撮影 → 出品 | 3日以内 | `title-keyword-writer` `description-copywriter` |
| 出品 → 規約チェック | 出品前 | `platform-policy-guard` |

**仕入から出品までを3日以内に固定します。**
ここが遅れると、ROIがいくら高くても回転日数が悪化し、月間粗利が落ちます。

### 5.3 この単価帯で最も重要なこと：状態記載の精度

単価¥15,000〜25,000の買い手は、**相場を知っている層**です。
彼らが見ているのは価格ではなく「**状態が正確に書かれているか**」です。

```
必須（`03-product-inspection.md` 第4章）：
・傷は mm 単位の実測で書く
・動作確認の「範囲」を書く（どこまで確認し、何をしていないか）
・付属品は「ある」と「ない」を両方書く
・欠点を良い点より先に書く
```

高単価帯では、**返品1件で月の粗利の1〜2割が消えます**。
返品率3%以下（`00-sedori-basics.md`）の維持が、ROI50%の維持より重要です。

## 6. 90日の実行計画（資金の投下順序）

**¥350,000を最初から全部使いません。** 検証してから積み増します。

### Phase A：検証（Day 1–30）／ 投下 ¥100,000

| # | やること | 完了条件 |
|---|---|---|
| 1 | 手数料・送料の実数を公式で確認 | `02-pricing-and-roi.md` 第2章が埋まる |
| 2 | 第1候補カテゴリを1つ選び、相場を実データで検証 | 主要20型番の相場・成約件数・出品者数を記録 |
| 3 | 上限仕入値の早見表を作る（相場×0.57） | 20型番分の表が完成 |
| 4 | 5〜8点を検証仕入（**上限¥100,000**） | ROI50%基準を満たす物のみ |
| 5 | 3日以内に全点出品 | リードタイム3日以下 |

**Day 30時点の判定**：ROI50%・回転45日を満たしたか。
満たさなければ、**カテゴリを変えて再検証**します。積み増しはしません。

### Phase B：拡大（Day 31–60）／ 投下 ¥250,000

| # | やること |
|---|---|
| 1 | 第1カテゴリの投下を¥200,000に拡大 |
| 2 | 第2候補カテゴリを¥50,000で検証開始 |
| 3 | 仕入先を店舗別に評価し、期待値の高い順に巡回を固定 |
| 4 | 30日超の在庫をメルカリへ移す運用を開始 |

### Phase C：定常運転（Day 61–90）／ 投下 ¥350,000

| # | やること |
|---|---|
| 1 | 2カテゴリで¥350,000をフル稼働 |
| 2 | 1時間あたり粗利を測定（拡大の可否判断） |
| 3 | 撮影・梱包・発送のマニュアル化（外注の準備） |
| 4 | 継続仕入ルート（同じ商品が繰り返し出る店・卸）の探索 |

## 8. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| **ROI50%の商品が見つからない** | 仕入が止まり、資金が遊ぶ | 基準を下げない。カテゴリを変える。見送りは正常な状態 |
| **回転が60日を超える** | 月間粗利が¥87,500まで低下 | 30日でメルカリへ移動。45日で値下げ |
| **高単価ゆえの返品** | 1件で月粗利の1〜2割が消える | 状態記載を実測で徹底。検品写真を必ず保管 |
| **バッテリー品の膨張** | 販売不可・発送不可 | 仕入時と保管中に必ずチェック |
| **真贋トラブル** | アカウント停止＝事業の即死 | ブランド品を扱わない。この戦略の前提 |
| **資金の遊休** | 機会損失 | 検証で基準未達なら、早くカテゴリを切り替える |

### 最も注意すべきこと
**ROI50%を狙うと「買えない期間」が必ず発生します。**
そこで基準を30%に緩めると、この戦略は崩壊します。
買えない日は、リサーチと相場表の精度を上げる日と位置づけてください。
