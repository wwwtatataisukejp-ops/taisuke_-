# 04 出品コピーライティング・撮影マニュアル

> 参照：05出品・販売部 全員
> 前提：`09-brand-voice.md`（禁止表現）と `03-product-inspection.md`（状態記述）に従うこと。

---

## 1. 出品文の目的

出品文の目的は「売ること」ではなく、
**「買うべき人にだけ、正しく理解して買ってもらうこと」**です。

- 曖昧に書いて売れた1件 → 返品・低評価・アカウント評価の毀損
- 正確に書いて売れなかった1件 → 損失ゼロ

**返品率3%・悪い評価率1%（`00-sedori-basics.md`）を守れない文章は、
売上を作っていても失敗**です。

## 2. タイトル設計（`title-keyword-writer` 用）

### 2.1 基本の語順
```
メーカー名 + シリーズ名 + 型番 + 主要スペック + 色 + 付属状態 + コンディション
```
例：
```
SONY WH-1000XM4 ワイヤレスヘッドホン ノイズキャンセリング ブラック 箱付き 中古良品
```

### 2.2 タイトルに入れるもの / 入れないもの
| ✅ 入れる | ❌ 入れない |
|---|---|
| 型番（ハイフンあり／なし両方を検討） | `★激安★` などの装飾記号 |
| メーカー・ブランドの正式名 | `即決` `早い者勝ち` などの煽り |
| 購入者が検索する一般名詞（例：ヘッドホン） | 関係のない人気キーワード（**規約違反**） |
| 色・容量・サイズなど識別に必要な情報 | `新品同様` `美品`（基準のない主観語） |
| 付属品の有無（箱付き・欠品あり） | 絵文字 |
| 世代・年式（同型番違いがある場合） | 他社ブランド名の併記（**キーワードスパム**） |

### 2.3 キーワードスパムの禁止（アカウント制約）
関係のないブランド名や人気商品名をタイトルに入れる行為は、
**多くの販路で規約違反**であり、アカウント警告の対象です。
CLAUDE.md 6.4 の赤線に準じ、**利益が出ても実施しません**。

### 2.4 検索されるキーワードの見つけ方
1. その商品を**買う人**が使う言葉を想像する（売る人の言葉ではない）
2. 販路の検索窓のサジェストを確認する
3. 実際に売れている出品のタイトルを3件確認する
4. 型番の表記ゆれを洗い出す（`WH-1000XM4` / `WH1000XM4` / `1000XM4`）
5. 用途・悩みの言葉を入れる（例：`ノイズキャンセリング` `通勤`）

### 2.5 自己チェック
- [ ] 型番が正確か（1文字違いは致命的）
- [ ] 日本語として自然に読めるか（**単語の羅列になっていないか**）
- [ ] 販路の文字数制限内か（→ `05-platform-rules.md`）
- [ ] 主観語・装飾記号が入っていないか
- [ ] 無関係なキーワードを入れていないか

## 3. 商品説明文（`description-copywriter` 用）

### 3.1 標準テンプレート
```
【商品】
SONY WH-1000XM4 ワイヤレスノイズキャンセリングヘッドホン ブラック

【コンディション】Bランク（中古・良好）

【状態（気になる点を先に記載しています）】
・天面 右下に 2mm の擦り傷が1箇所あります
・底面 全体に薄い使用擦れがあります
・イヤーパッドに劣化・べたつきはありません

【動作確認】
・電源投入、音出し、Bluetooth接続まで確認しました（2026/07/27）
・分解点検はしていません

【付属品】
・あり：本体、充電用USBケーブル、収納ポーチ
・なし：外箱、説明書、保証書、音声ケーブル

【発送について】
・ご入金確認後、1〜2営業日以内に発送します
・宅配便（追跡あり）で発送します

【ご確認ください】
・中古品のため、記載以外の細かな使用感がある場合があります
・上記の状態にご同意のうえ、ご購入をお願いいたします
```

### 3.2 順序のルール（違反は差し戻し）
```
① 商品の特定 → ② コンディション → ③ 【欠点】 → ④ 良い点
→ ⑤ 動作確認の範囲 → ⑥ 付属品（ある／ない両方）→ ⑦ 発送 → ⑧ 注意事項
```

**③（欠点）を④（良い点）より後に書いた文章は、無条件で差し戻し**です。
`09-brand-voice.md` の「誠実」原則そのものです。

### 3.3 書いてはいけない表現（`09-brand-voice.md` より抜粋・再掲）
| ❌ 禁止 | ✅ 代替 |
|---|---|
| 新品同様／美品 | 使用感ほぼなし。傷：右下に2mm（実測） |
| 正規品保証／鑑定済み | 購入店：◯◯／付属品：保証書あり |
| 完全動作保証 | 電源投入・音出しまで確認済み |
| ノークレーム・ノーリターン | 記載の状態にご同意のうえご購入ください |
| 効く／治る／痩せる | パッケージ記載の内容を転記のみ |
| 絶対に値上がりします | 生産終了品です（2024年終了・メーカー発表） |
| 業界最安値 | 2026/07/27時点で当店調べ最安帯 |
| 激安／レア | 取扱店が少ない商品です |

### 3.4 「気になる点を先に」の効果
| 指標 | 欠点を後に書く | 欠点を先に書く |
|---|---|---|
| 成約率 | やや高い | やや低い |
| 返品率 | **高い** | 低い |
| 低評価率 | **高い** | 低い |
| アカウント健全性 | 悪化 | 維持 |

3大制約の「アカウント制約」が最優先である以上、**後者を選びます**。

## 4. 商品撮影（`photo-director` 用）

### 4.1 必須カット（この順序で並べる）
| No | カット | 目的 |
|---|---|---|
| 1 | 正面全体（メイン画像） | 一覧で目を引く・商品の特定 |
| 2 | 背面 | 全体像の把握 |
| 3 | 側面（左右） | 同上 |
| 4 | 天面・底面 | 同上 |
| 5 | **欠点の接写** | 返品予防（最重要） |
| 6 | 型番・シリアルの接写 | 個体の特定 |
| 7 | 付属品を並べた1枚 | 同梱物の明示 |
| 8 | サイズ比較（定規や身近な物と） | サイズ誤認の防止 |

### 4.2 欠点の写真は必ず入れる
欠点を文章に書いても、**写真がないと「聞いていない」と言われます**。
`03-product-inspection.md` で記録した欠点は、**すべて写真化**してください。

### 4.3 撮影の基本設定
| 項目 | 推奨 | 理由 |
|---|---|---|
| 光源 | 自然光（曇天の窓際）または白色LED2灯 | 影と色被りを減らす |
| 背景 | 白または無地グレー | 商品が主役になる |
| 角度 | やや斜め上45度（メイン） | 立体感が出る |
| ピント | 商品の手前1/3に合わせる | 全体がシャープに見える |
| 画面占有 | 商品が画面の80〜90% | 一覧で視認しやすい |
| 向き | 販路の推奨比率に合わせる | → `05-platform-rules.md` |

### 4.4 やってはいけない加工
| ❌ 禁止 | 理由 |
|---|---|
| 傷・汚れを消す・ぼかす | 事実の隠蔽。返品とトラブルの原因 |
| 実物と異なる色に補正する | 色違いクレームの原因 |
| メーカー公式画像を無断使用 | 著作権侵害・規約違反 |
| 他人の出品画像の転用 | 同上 |
| 付属しないものを写り込ませる | 誤認。**必ず「撮影小物は付属しません」と明記** |
| 過度な文字入れ・枠装飾 | 販路によって規約違反 |

明るさ・水平の補正は可。**「事実を変えない補正」だけが許容**されます。

## 5. 販路別の出し分け（`platform-optimizer` 用）

詳細な仕様は `05-platform-rules.md` を参照。ここでは**文章の書き分け方針**のみ。

| 販路 | 読み手 | 文章の方針 |
|---|---|---|
| Amazon | 型番で探す指名買い | 簡潔・スペック中心。コンディション説明欄は事実のみ |
| メルカリ | スマホで流し読み | 短文・箇条書き・冒頭3行が勝負。値下げ交渉前提の価格設計 |
| ヤフオク! | 相場を知る人・コレクター | 詳細な状態記述と写真点数が効く。専門用語も可 |
| 楽天 | 比較検討層 | ショップとしての信頼情報（発送・保証）を厚く |
| eBay | 海外・言語が違う | 曖昧語を避け、**寸法と状態を数値で**。返品条件を明記 |

### 5.1 メルカリ向け（冒頭3行が全て）
```
SONY WH-1000XM4 ノイキャンヘッドホン ブラック
Bランク／天面に2mmの擦り傷あり／動作確認済み
付属：本体・充電ケーブル・ポーチ（箱と説明書はありません）
```

### 5.2 使い回しの禁止
同じ文章を全販路にコピーすると、
**文字数制限違反・禁止表現・他販路名の記載**（規約違反）が起きます。
`platform-optimizer` が販路ごとに必ず整形してください。

## 6. 顧客対応の文章（`cs-responder` 用）

### 6.1 返信の型
```
1. お礼または謝意（1行）
2. 結論（できる／できない を明示）（1行）
3. 理由と代替案（2〜3行）
4. 次のアクション（1行）
```

### 6.2 値下げ交渉への返信例
```
ご質問ありがとうございます。
現在 ¥12,800 でのご提供とさせていただいております。

こちらの価格は、状態（Bランク・天面に2mmの擦り傷）と
付属品の内容を踏まえて設定しております。

ご検討のほど、よろしくお願いいたします。
```

**やってはいけない返信**
- 「値下げ不可です」だけ（高圧的）
- 「他の方と交渉中です」（事実でないなら虚偽）
- 損益分岐売価（`02-pricing-and-roi.md`）を下回る即答の値下げ

### 6.3 クレーム初動の型
```
1. 事実の確認（何が・いつ・どの状態で）  ← 謝罪より先
2. 写真の依頼（現物の状態）
3. こちらの記録との照合（検品写真）
4. 対応方針の提示（返品・一部返金・交換）
5. 再発防止（検品／説明文のどこを直すか）
```

**非がある場合のみ謝罪**します。過剰な謝罪は責任範囲を曖昧にし、
`fraud-risk-officer` 案件（悪質クレーム）で不利になります。

## 7. 出品前の最終チェックリスト

### 文章
- [ ] 欠点を良い点より先に書いたか
- [ ] 実測値で書いたか（主観語を使っていないか）
- [ ] 付属品の「ある」「ない」を両方書いたか
- [ ] 動作確認の**範囲**を書いたか
- [ ] 禁止表現（`09-brand-voice.md` 第2章）がゼロか
- [ ] 販路の文字数制限内か
- [ ] 他販路の名前を書いていないか

### 写真
- [ ] 欠点の接写が入っているか
- [ ] 型番が読める写真があるか
- [ ] 付属品一覧の写真があるか
- [ ] 事実を変える加工をしていないか
- [ ] 他人の画像を使っていないか

### 価格
- [ ] `roi-calculator` の数字と一致しているか
- [ ] 損益分岐売価を上回っているか

### 最終
- [ ] `platform-policy-guard` の規約チェックを通したか（**P2の必須工程**）
