> 参照：08リスク・法務部 全員 ／ `overseas-buyer` ／ `authenticity-checker`

---

## ⚠️ 最重要の前提

**このマニュアルは法的助言ではありません。**
法令は改正され、個別の事案によって結論が変わります。

```
このマニュアルの役割 = 「危険を検知し、止めること」
このマニュアルの限界 = 「最終的な適法性を保証すること」はできない
```

`law-checker` の判定は次の3択のみです。

| 判定 | 意味 | アクション |
|---|---|---|
| **問題なし** | 明確に適法・許可不要と確認できた | 続行 |
| **要確認** | 判断に専門家または公的機関の確認が必要 | **STOP**。社長へエスカレーション |
| **不可** | 明確に違法・無許可では扱えない | **NO GO** |

**「要確認」を自分の判断で「問題なし」に変えてはいけません。**
CLAUDE.md 第7章のエスカレーション条件3に該当します。

## 1. 事業の基盤：古物営業法

### 1.1 古物商許可
中古品を**転売目的で仕入れて販売**する場合、古物商許可が必要になるのが原則です。

| 項目 | 内容 |
|---|---|
| 許可権者 | 営業所を管轄する都道府県公安委員会（申請は所轄警察署） |
| 必要になる典型 | 中古品を転売目的で買い取り、販売する |
| 不要とされる典型 | 自分が使うために買った物を売る／新品を仕入れて売る（要個別確認） |
| 無許可営業 | 罰則の対象。**事業の存続に関わる** |

**判断に迷う場合は、必ず所轄の警察署（生活安全課）に確認してください。**
`law-checker` は、この確認をしていない状態を「要確認」として扱います。

### 1.2 古物台帳（取引記録）
古物営業では、一定の取引について**記録の作成・保存**が求められます。

記録すべき項目の例：
- 取引年月日
- 古物の品目・数量
- 古物の特徴（型番・シリアル等）
- 相手方の氏名・住所・職業・年齢
- 本人確認の方法

**具体的な対象取引・保存期間・様式は、所轄警察署の指示に従ってください。**

> 実務メモ：この記録は `inventory-manager` の在庫台帳と項目が重なります。
> 台帳を二重管理せず、**在庫台帳に古物台帳の必要項目を統合**すると運用が楽になります。
> ただし**法定の要件を満たしているか**は所轄で必ず確認すること。

### 1.3 その他の義務（要確認）
- 許可証の掲示、行商の届出
- 標識（プレート）の掲示
- 営業所の変更等の届出
- 不正品と疑われる物品を発見した場合の申告

## 2. 通信販売としての義務：特定商取引法

ネット販売は「通信販売」に該当し、**事業者の情報表示**などが求められるのが原則です。

### 2.1 表示が求められる項目の例
- 販売価格、送料などの費用
- 代金の支払時期・方法
- 引渡し時期
- 返品の可否と条件（**返品特約**）
- 事業者の氏名（名称）、住所、電話番号
- （法人の場合）代表者名 等

### 2.2 特に注意
- **返品特約を表示していない場合、法定のルールが適用**されます。
  返品条件は、販路の規約と併せて必ず明示してください。
- 「ノークレーム・ノーリターン」と書けば返品を拒否できる、という理解は誤りです。
  → `09-brand-voice.md` の禁止表現に指定済み。
- 個人での出品でも、**継続的・反復的な販売は事業者と評価され得ます**。
- プラットフォームによっては、事業者情報の登録欄が用意されています。

**表示義務の具体的な範囲・記載方法は要確認事項**です。

## 3. 表示の適正化：景品表示法

### 3.1 禁止される2つの表示
| 種別 | 内容 | せどりでの例 |
|---|---|---|
| **優良誤認** | 品質・規格を実際より著しく優良に見せる | 「新品同様」（実際は使用感あり）、「正規品保証」（根拠なし） |
| **有利誤認** | 価格・取引条件を実際より有利に見せる | 「業界最安値」（根拠なし）、根拠のない二重価格表示 |

### 3.2 二重価格表示の注意
「定価¥30,000 → ¥12,800」のような表示は、
**比較対照価格に合理的な根拠が必要**です。
根拠を示せない比較価格は表示しないでください。

### 3.3 対応
`09-brand-voice.md` の禁止表現リストは、この法律への対応として設計されています。
**禁止表現を使わないことが、そのまま景表法対策**になります。

## 4. 商品カテゴリ別の規制（仕入前に必ず確認）

### 4.1 一覧（`law-checker` の初期スクリーニング）

| カテゴリ | 関係する主な法令 | 必要になり得るもの | 判定 |
|---|---|---|---|
| 中古品全般 | 古物営業法 | 古物商許可 | 許可なしは**不可** |
| 電気用品（コンセントに挿す物） | 電気用品安全法 | **PSEマーク**の表示 | 表示なしは**要確認〜不可** |
| 無線機器（Bluetooth/Wi-Fi） | 電波法 | **技適マーク** | 未取得機の使用・販売は**要確認〜不可** |
| 医薬品・医薬部外品・化粧品・医療機器 | 薬機法 | 販売業の許可・届出等 | 原則**要確認**。無許可は不可 |
| 健康食品・サプリ | 薬機法・食品表示法 | — | **効能効果の表示が不可**。要確認 |
| 食品 | 食品衛生法 | 営業許可・届出 | 原則**要確認** |
| 酒類 | 酒税法 | **酒類販売業免許** | 免許なしは**不可** |
| チケット（興行等） | チケット不正転売禁止法 | — | 特定興行入場券の不正転売は**不可** |
| ブランド品 | 商標法・不正競争防止法 | — | 偽造品は**不可**。真贋グレーは**不可** |
| キャラクター・アニメ関連 | 著作権法・商標法 | — | 無許諾の複製品は**不可** |
| 銃刀類・模造品 | 銃刀法 | — | **要確認**。多くが不可 |
| 動植物・皮革・象牙等 | 種の保存法・ワシントン条約 | 登録・許可 | **要確認**。輸出入は特に厳格 |
| 自動車・バイク部品 | 道路運送車両法 | — | 保安基準・車検適合性を**要確認** |
| 医療機器（家庭用含む） | 薬機法 | 販売業の届出等 | **要確認** |
| 化学物質・危険物 | 消防法等 | — | **要確認**。配送も制限 |
| リコール対象品 | 消費生活用製品安全法等 | — | 販売しない |

### 4.2 電気用品安全法（PSE）の実務
- 対象の電気用品には**PSEマークの表示**が求められます
- **マークのない対象製品を販売できない場合があります**
- 中古品の販売も対象となり得ます
- 海外製品・輸入品は特に注意

**確認手順**
```
① 製品にPSEマーク（◇または〇の中にPSE）があるか目視確認
② ない場合 → その製品が対象品目か確認
③ 対象品目なら → 「不可」または「要確認」
④ 判断できない → 経済産業省の窓口・所管に確認
```

### 4.3 電波法（技適）の実務
- 日本国内で使用する無線機器には、技術基準適合証明（**技適マーク**）が必要になります
- 海外版のスマホ・Bluetooth機器は**技適未取得の場合があります**
- 技適のない機器の**使用**が問題になる場合があり、販売も慎重な判断が必要です

**海外仕入（`overseas-buyer`）では、技適の確認を必須工程**としてください。

### 4.4 薬機法の実務（最も事故が多い領域）
```
NGの典型：
  「このサプリで痩せます」「肌荒れが治ります」
  → 医薬品的な効能効果の標榜。健康食品・化粧品では不可

安全側の運用：
  パッケージやメーカーの表示内容を**転記するのみ**。
  自分の言葉で効果を説明しない。
```
→ `09-brand-voice.md` の禁止表現「効く／治る／痩せる」はこの対応です。

## 5. 権利侵害（真贋・商標・著作権）

### 5.1 基本原則
```
真贋がグレー ＝ 販売しない（CLAUDE.md 6.4 赤線1）
```

### 5.2 権利侵害になり得る類型
| 類型 | 例 |
|---|---|
| 偽造品（コピー品） | ブランドロゴを模した製品 |
| 無許諾の複製品 | キャラクターを無断で印刷した物、海賊版 |
| 商標の不適切な使用 | 無関係な商品タイトルにブランド名を入れる |
| 画像の無断使用 | メーカー公式画像・他出品者の写真の転用 |
| 並行輸入品の扱い | **要確認**。真正品であっても販路や権利者の制限がある場合がある |

### 5.3 権利者から申立てを受けたとき
```
① 該当出品を即座に停止（判断を待たない）
② 社長へ即時報告（CLAUDE.md 第7章 条件4）
③ 仕入経路の証拠（レシート・請求書）を収集
④ 販路の指定手続に従って対応（→ `05-platform-rules.md` 第4章）
⑤ 内容が複雑・高額な場合は、弁護士への相談を検討
```

**仕入レシートがないと、真正品であることを示す手段がありません。**
`bookkeeper` のレシート保管は、法務上の防御資料でもあります。

## 6. 海外仕入・越境販売（`overseas-buyer` 用）

### 6.1 輸入時のチェック
- [ ] その品目は**日本に輸入できる**か（輸入禁止・規制品でないか）
- [ ] 関税・消費税・通関手数料を原価に入れたか
- [ ] 電気用品なら PSE、無線機器なら技適を満たすか
- [ ] 食品・化粧品・医薬品に該当しないか（該当すれば手続が別途必要）
- [ ] 商標権者の権利を侵害しないか（模倣品は**税関で差止め**の対象）
- [ ] ワシントン条約の対象素材（皮革・象牙・べっ甲等）を含まないか

### 6.2 輸出時のチェック
- [ ] 日本から**輸出できる**品目か
- [ ] 相手国で**輸入できる**品目か（相手国の規制は自分で確認）
- [ ] バッテリー・液体・スプレー等、**配送の制限**に触れないか
- [ ] 関税・付加価値税の負担者を明確にしたか

**海外案件は、国内案件より1段階厳しく判定してください。**
不明点が1つでもあれば「要確認」で止めます。

## 7. `law-checker` の標準チェックフロー

```
STEP 1 : カテゴリ判定
  第4章の表で、該当カテゴリを特定する

STEP 2 : 許可・資格の確認
  古物商許可はあるか
  カテゴリ固有の許可・免許・届出は必要か、あるか

STEP 3 : 製品固有の表示確認
  PSE / 技適 / 品質表示 / 期限表示

STEP 4 : 権利の確認
  真贋、商標、著作権、画像の権利

STEP 5 : 表示の確認
  景表法（優良誤認・有利誤認）
  薬機法（効能効果の標榜）
  特商法（事業者表示・返品特約）

STEP 6 : 判定
  問題なし / 要確認 / 不可
  ※ 1つでも不明があれば「要確認」以上
```

### 出力フォーマット
```
【判定】要確認

【該当カテゴリ】電気用品（電気用品安全法）

【確認できたこと】
・製品本体にPSEマークが確認できない（写真より／2026/07/27）

【確認できていないこと】
・当該品目が電気用品安全法の対象品目に該当するか

【必要なアクション】
1. 製品の型番から対象品目該当性を確認する
2. 判断できない場合、経済産業省の相談窓口に照会する

【この判定の限界】
・本判定は法的助言ではありません。最終判断は所管官庁または専門家に確認してください。

【社長判断が必要な点】
・確認が取れるまで仕入を保留するか、案件自体を見送るか
```

## 8. 迷ったときの優先順位

```
① 人の安全（危険な製品を流通させない）
② 法令遵守
③ プラットフォーム規約
④ 利益
```

**この順序を入れ替えることは、いかなる理由でも認められません。**

## 9. 相談先の整理

| 内容 | 相談先 |
|---|---|
| 古物商許可・古物台帳 | 所轄警察署 生活安全課 |
| 電気用品安全法（PSE） | 経済産業省の相談窓口 |
| 電波法（技適） | 総務省 総合通信局 |
| 薬機法・食品衛生法 | 都道府県の薬務課・保健所 |
| 酒類販売免許 | 所轄税務署 |
| 景品表示法 | 消費者庁 |
| 輸出入の可否・関税 | 税関の相談窓口 |
| 権利侵害・訴訟 | 弁護士 |
| 税務 | 税理士（→ `08-accounting-tax.md`） |

**「ネットで調べた」は確認したことになりません。**
一次情報（官公庁のページ）または窓口への照会をもって「確認済み」とします。
