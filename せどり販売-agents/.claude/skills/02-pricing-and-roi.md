## ⚠️ 手数料・送料の数値について（最重要の注意）

**各販路の手数料率・送料は改定されます。**
本マニュアルの数値は「参考値」であり、**確定値として計算に使ってはいけません**。

計算前に必ず以下を実行してください。

```
① 下の「参考値」で概算し、GO/NO GO の当たりを付ける
② GO 方向なら、販路の公式手数料ページで実数を確認する
③ 確認した実数で再計算し、それを最終判定とする
④ 出力には「手数料は 2026/07/27 時点の公式表を確認済み」と明記する
```

未確認の参考値で判定を出す場合は、必ず
`【要検証】手数料は参考値。公式確認前` と明記してください。

## 1. 計算式（すべての価格判断の土台）

```
仕入原価 = 仕入値 + 仕入送料 + 仕入時手数料
販売経費 = 販売手数料 + 出荷送料 + 梱包材費 + 広告費
粗利     = 想定売価 − 仕入原価 − 販売経費
粗利率   = 粗利 ÷ 想定売価 × 100
ROI      = 粗利 ÷ 仕入原価 × 100
実質年利回り = ROI × (365 ÷ 回転日数)
```

### 損益分岐売価（この価格を下回ると赤字）
```
損益分岐売価 = (仕入原価 + 出荷送料 + 梱包材費) ÷ (1 − 手数料率)
```
例：仕入原価¥8,000・送料¥250・梱包¥70・手数料率10%
→ `8,320 ÷ 0.9 = ¥9,245` → **¥9,245 を下回ったら赤字**

**値下げ判断のときは、必ず先に損益分岐売価を計算**してください。
`repricing-operator` はこの数字なしに値下げ幅を提案してはいけません。

### 目標粗利率から売価を逆算する
```
必要売価 = (仕入原価 + 出荷送料 + 梱包材費) ÷ (1 − 手数料率 − 目標粗利率)
```
例：上と同条件で粗利率20%を狙う
→ `8,320 ÷ (1 − 0.10 − 0.20) = 8,320 ÷ 0.70 = ¥11,886`

| 資材 | 単価目安 | 備考 |

## 4. 値付けの5方針（`pricing-strategist` が選択）

| 方針 | 内容 | 使う場面 | リスク |
|---|---|---|---|
| **相場追随** | 相場中央値に合わせる | 実績が多く競合も多い商品 | 価格競争に巻き込まれる |
| **最安追随** | 最安値に合わせる／わずかに下 | 早期に現金化したい | 消耗戦。粗利率が削れる |
| **上位価格** | 相場より高く設定 | 状態が明確に良い／付属品完備 | 回転が遅くなる |
| **希少価格** | 市場に出品がほぼない | 生産終了・入手困難品 | 相場未確定。長期化しやすい |
| **段階値下げ** | 高めに出し、日数で自動的に下げる | 相場が読みにくい商品 | 放置すると滞留 |

### 段階値下げの標準スケジュール（`repricing-operator` の既定運用）
| 経過日数 | アクション | 下限 |
|---|---|---|
| 0〜14日 | 初期価格を維持 | — |
| 15日 | −5% | 損益分岐売価を下回らない |
| 30日 | −10%（初期比） | 同上 |
| 45日 | −15%（初期比）＋ 販路変更を検討 | 同上 |
| 60日 | 粗利ゼロまで許容して現金化を優先 | 損益分岐売価 |
| 90日 | **損切り判断**（`kpi-analyst`・`tax-advisor` と協議） | — |

**「損益分岐売価を下回る値下げ」は、必ず社長判断**とします。

## 5. 損切りの考え方（最も間違えやすい領域）

### 5.1 仕入値は判断材料ではない（サンクコスト）
`¥8,000 で仕入れたから ¥8,000 以上で売りたい` は**誤った判断**です。
判断すべきは「**今この在庫を現金に変えたら、その現金で何ができるか**」です。

```
損切り判断の問い：
  この在庫を今 ¥5,000 で売って得た現金を、
  ROI 30% で回転45日の商品に投じた場合、
  90日後にいくらになるか？
      ↓
  「売れるのを待つ」より大きいなら、損切りが正解。
```

### 5.2 損切りの判定式
```
待機の期待値 = 想定売価 × 90日以内に売れる確率 − 保管コスト
損切りの期待値 = 即時売却額 × (1 + ROI基準) ^ (90 ÷ 回転日数)
```
厳密な確率は出せないので、`kpi-analyst` が実績から3段階（高/中/低）で判断します。

### 5.3 損切りを先送りしてはいけない理由
1. 相場は多くの場合、時間とともに下がる（特に家電・ガジェット）
2. 保管スペースと管理の手間が継続的にかかる
3. **資金が拘束され、他の GO 案件を逃す**（機会損失が最大の損）

## 6. 売却タイミングの設計（`sell-timing-planner` 用）

### 6.1 待つ価値がある条件（すべて満たすときのみ）
1. 価格上昇の**具体的な根拠**がある（生産終了・供給停止・イベント）
2. 上昇までの期間が**見積もれる**
3. その期間、資金を拘束しても資金繰りに支障がない
4. 保管しても劣化しない（電池・食品・シーズン品は要注意）

**「なんとなく上がりそう」は待つ理由になりません。**

### 6.2 季節需要のカレンダー（自社実績で更新）
| 時期 | 需要が上がる | 需要が下がる |
|---|---|---|
| 1〜2月 | 受験・防寒・新生活準備 | レジャー |
| 3〜4月 | 新生活家電・入学用品 | 冬物 |
| 5〜6月 | 梅雨対策・父の日 | — |
| 7〜8月 | 夏物家電・アウトドア・自由研究 | 暖房 |
| 9〜10月 | 行楽・運動会・ハロウィン | 夏物 |
| 11〜12月 | クリスマス・年末商戦・福袋需要 | — |

**シーズン品は「シーズン開始の1〜2ヶ月前」に出品**します。
シーズン終了後の在庫は、次シーズンまで持つ判断を**必ず数値で**行ってください
（11ヶ月の資金拘束に見合うか）。

## 7. KPI 定義（`kpi-analyst` と共通）

| KPI | 計算式 | 目標 |
|---|---|---|
| 月間売上 | 期間内の売却額合計 | 社長設定 |
| 月間粗利 | 売上 − 仕入原価 − 販売経費 | 社長設定 |
| 平均粗利率 | 月間粗利 ÷ 月間売上 | 20%以上 |
| 平均ROI | 月間粗利 ÷ 月間仕入原価 | 30%以上 |
| 平均回転日数 | Σ(各商品の回転日数) ÷ 売却件数 | 45日以内 |
| 在庫回転率 | 月間売上原価 ÷ 平均在庫評価額 | 高いほど良い |
| 在庫比率 | 在庫評価額 ÷ 総運転資金 | 70%以下 |
| 滞留在庫比率 | 90日超在庫額 ÷ 在庫評価額 | 10%以下 |
| 1時間あたり粗利 | 月間粗利 ÷ 総稼働時間 | 社長設定（時間制約の指標） |
| 返品率 | 返品件数 ÷ 売却件数 | 3%以下 |

### 「1時間あたり粗利」を必ず見る理由
CLAUDE.md の3大制約の2番目は**時間制約**です。
粗利が伸びていても、稼働時間がそれ以上に伸びていれば事業は悪化しています。
`kpi-analyst` は月次レビューで必ずこの指標を報告してください。

## 8. 計算時の頻出ミス（チェックリスト）

- [ ] 出品価格を相場として使っていないか（→ 売却実績を使う）
- [ ] 手数料を忘れていないか
- [ ] 出荷送料を忘れていないか／小さいサイズで見積もっていないか
- [ ] 梱包材費を0円にしていないか
- [ ] 仕入時の送料・手数料を仕入原価に入れたか
- [ ] ポイント還元を利益に含めていないか
- [ ] 消費税の扱いを税込／税抜で混在させていないか
- [ ] 回転日数を「売却まで」ではなく「**入金まで**」で数えたか
- [ ] 複数個仕入れた場合、1個あたりで計算したか
- [ ] 最悪シナリオ（相場20%下落）を計算したか
