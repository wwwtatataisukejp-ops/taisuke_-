# 03 検品・鑑定マニュアル

> 参照：03商品鑑定・検品部 全員 ／ `description-copywriter` ／ `returns-handler`
> 原則：**検品の目的は「良く見せる」ことではなく「返品とトラブルをゼロにする」こと**。

---

## 1. 検品の基本順序

```
① 真贋（本物か）        → グレーなら即STOP。以降の工程に進まない
② 安全性（危険がないか） → リコール・破損・液漏れ・発熱
③ 動作（機能するか）     → 電源・主要機能・付属品
④ 外観（状態はどうか）   → 傷・汚れ・欠品を実測で記録
⑤ ランク付け            → S/A/B/C/D を確定
⑥ 記録                  → 写真＋文章で証拠を残す
```

**①で止まった商品を④まで進めてはいけません。**
状態が良いほど「本物だと思いたい」バイアスがかかります。順序を守ってください。

## 2. 真贋判定（`authenticity-checker` 用）

### 2.1 判定は3択のみ
| 判定 | 意味 | 次のアクション |
|---|---|---|
| **本物と確認できた** | 客観的根拠が複数ある | 出品可 |
| **グレー（判断不能）** | 根拠が不足／矛盾がある | **仕入中止 or 出品中止**。売らない |
| **偽造の疑いが強い** | 明確な相違点がある | 販売しない。仕入済みなら販路と権利者の指示に従う |

### 2.2 最重要ルール
```
グレー ＝ 販売しない
```
「たぶん本物」「9割本物」は**すべてグレー**です。
真贋トラブルは、返金だけでなく**アカウント停止**につながります。
CLAUDE.md の3大制約「アカウント制約」により、**利益より安全が常に優先**です。

### 2.3 確認する観点（万能なチェックリストは存在しない）
| 観点 | 見るもの | 注意 |
|---|---|---|
| 入手経路 | 購入店・レシート・保証書 | 経路不明はリスク加点 |
| 個体情報 | シリアル・製造番号・ロット | 番号の**有無**だけで断定しない |
| 縫製・成形 | 縫い目・接着・バリ・歪み | 個体差と偽造を混同しない |
| 印字・刻印 | フォント・位置・深さ | 年代で正規品も変わる |
| 付属品 | 箱・保証書・タグ・説明書 | 付属品だけの偽造も存在する |
| 重量・寸法 | 公称値との差 | 実測して比較 |
| 価格の異常 | 相場より極端に安い | **理由を説明できない安さは危険信号** |

### 2.4 断定してはいけないこと
- 自社検品の結果を「**正規品保証**」「**鑑定済み**」と表現すること（`09-brand-voice.md` 禁止表現）
- 書いてよいのは**事実のみ**：`購入店：◯◯／付属品：保証書あり（購入日 2024/03/12 記載）`

### 2.5 迷ったときのエスカレーション
- 高額ブランド品・限定品 → **社長判断**（CLAUDE.md 第7章）
- 商標・並行輸入の可否が絡む → `law-checker`
- 権利者からの申立てが来ている → `platform-policy-guard` + 社長へ即時報告

## 3. コンディションランク定義（`condition-grader` 用）

**全部門・全販路でこの定義を共通言語として使います。**

| ランク | 定義 | 外観 | 動作 | 付属品 |
|---|---|---|---|---|
| **S** | 新品・未開封 | 未開封または未使用 | 未確認（未開封のため） | 完品 |
| **A** | 未使用に近い／極美品 | 使用感がほぼない。傷なし | 全機能正常 | ほぼ完品 |
| **B** | 中古・良好 | 使用感あり。**軽微な傷が実測で記載できる範囲** | 全機能正常 | 主要付属品あり |
| **C** | 中古・傷や汚れあり | 明確な傷・汚れ・色褪せ | 主要機能は正常 | 欠品あり |
| **D** | ジャンク・難あり | 破損・欠損 | 不動作または機能制限 | 欠品多数 |

### ランク付けの3原則
1. **迷ったら1つ下のランク**にする（過大評価は返品を生む）
2. ランク名だけでなく、**必ず実測の欠点記述を添える**
3. 販路のコンディション表記に変換するときは、`05-platform-rules.md` の対応表を使う

### やってはいけないランク付け
- 「美品」「新品同様」など、**基準のない主観語をランク代わりに使う**
- 動作未確認なのに「動作確認済み」と書く
- 欠品を「※画像のものが全てです」だけで済ませる（→ 何がないかを文字で書く）

## 4. 状態記述のフォーマット（返品を防ぐ書き方）

### 4.1 必須の記述項目
```
■ ランク：Bランク（中古・良好）
■ 傷・汚れ（実測）
  ・天面 右下に 2mm の擦り傷が1箇所
  ・底面 全体に薄い使用擦れ
■ 動作確認の範囲
  ・電源投入、音出し、Bluetooth接続まで確認（2026/07/27）
  ・分解点検はしていません
■ 付属品
  ・あり：本体、充電ケーブル、収納ポーチ
  ・なし：外箱、説明書、保証書
■ 匂い・その他
  ・タバコ／ペット臭：なし
```

### 4.2 「あるもの」と「ないもの」を必ず両方書く
付属品は**欠品を明記**しないと、返品理由になります。
「なし」の欄が空の場合、`description-copywriter` は出品してはいけません。

### 4.3 実測の徹底
| ❌ 主観 | ✅ 実測 |
|---|---|
| 小傷あり | 右下に2mmの擦り傷が1箇所 |
| きれいです | 目立つ傷は確認できず（蛍光灯下・30cmの距離で確認） |
| 少し汚れ | 側面に1cm四方の変色 |
| 動作良好 | 電源投入・音出しまで確認（分解点検なし） |

## 5. カテゴリ別 検品チェックリスト

### 5.1 家電・AV機器
- [ ] 通電するか
- [ ] 主要機能が動くか（**どこまで確認したか**を記録）
- [ ] 異音・異臭・発熱がないか
- [ ] 電源コード・プラグの被覆に破損がないか
- [ ] **PSEマークの有無**（→ なければ `law-checker` へ）
- [ ] リコール対象製品でないか（型番で確認）
- [ ] 付属品（ケーブル・リモコン・アダプタ）の有無

### 5.2 無線機器（Bluetooth・Wi-Fi 製品）
- [ ] **技適マークの有無**（→ なければ販売不可の可能性。`law-checker` へ）
- [ ] 海外版でないか（技適未取得機の販売は電波法上の問題）
- [ ] ペアリングが成立するか

### 5.3 バッテリー内蔵製品
- [ ] **膨張していないか**（膨張品は販売禁止・発送も危険）
- [ ] 充電できるか／充電の持ちに異常がないか
- [ ] 液漏れ・変形・異臭がないか
- [ ] 配送方法にバッテリー制限がないか（→ `06-logistics-ops.md`）

### 5.4 衣類・バッグ・靴
- [ ] 真贋（ブランド品は必ず①の工程）
- [ ] シミ・虫食い・毛玉・ほつれ（位置と大きさを実測）
- [ ] 匂い（タバコ・香水・カビ・防虫剤）
- [ ] ファスナー・ボタン・金具の動作
- [ ] 洗濯表示タグ・ブランドタグの有無
- [ ] 実寸採寸（表記サイズではなく**実測cm**）

### 5.5 書籍・メディア
- [ ] 書き込み・線引き・押印
- [ ] 日焼け・水濡れ跡・折れ
- [ ] **付録・帯・カード・特典の有無**（欠品トラブルの最頻出）
- [ ] ディスクの傷（再生確認の可否）
- [ ] シリアルコード類の使用済み／未使用

### 5.6 おもちゃ・ホビー
- [ ] 欠品（パーツ・説明書・シール）
- [ ] 開封済みかどうか
- [ ] 塗装剥がれ・変形・日焼け
- [ ] 電池の液漏れ跡
- [ ] 版権・商標の問題がないか（→ 疑わしければ `law-checker`）

### 5.7 食品・化粧品・健康関連
- [ ] **賞味／消費期限・使用期限**
- [ ] 開封済みでないか
- [ ] 保管状態（温度・直射日光）
- [ ] 該当法令（食品衛生法・薬機法）→ **`law-checker` に必ず回す**
- [ ] 販路の出品規約で扱えるか

## 6. 写真による記録（返品時の証拠）

出品用の写真とは別に、**検品記録用の写真を必ず残します**。

| 撮るもの | 目的 |
|---|---|
| 全体（6面） | 状態の全体証明 |
| 欠点の接写（定規と一緒に） | 傷のサイズの証明 |
| シリアル・型番の接写 | 個体の同一性証明 |
| 付属品を並べた1枚 | 同梱物の証明 |
| 梱包直前の状態 | すり替え・破損クレームへの反証 |

**保存ルール**：`YYYYMMDD_型番_連番.jpg` で、売却後**6ヶ月以上**保管。
すり替え詐欺（`fraud-risk-officer` 案件）では、この写真が唯一の反証材料になります。

## 7. クリーニング・整備の判断（`refurb-cleaner` 用）

### 7.1 手を加える価値があるかの判定式
```
整備の期待効果 = (整備後の想定売価 − 整備前の想定売価)
              − 資材費 − (作業時間 × 目標時給)

期待効果 > 0 のときのみ実施
```

**作業時間を無料と考えるのが最大の誤り**です。
CLAUDE.md の時間制約に従い、必ず時給換算で評価してください。

### 7.2 やってよい整備 / やってはいけない整備
| ✅ やってよい | ❌ やってはいけない |
|---|---|
| 外装の清拭・埃取り | 分解を伴う修理（動作保証責任が生じる） |
| 接点の清掃 | 傷を埋めて**見えなくする**加工 |
| 匂い取り・陰干し | 型番・シリアルの消去 |
| 付属品の補完（**補完した旨を明記**） | 純正品でない部品を純正と偽る |
| 箱・袋の交換（**交換した旨を明記**） | ブランドロゴ・タグの付け替え |

### 7.3 整備した場合の記載義務
整備・清掃・部品補完を行った場合、**必ず説明文に明記**します。

```
・出品前にクリーニング済み（外装の清拭のみ。分解洗浄はしていません）
・充電ケーブルは純正品ではない社外品を付属しています
```

**明記しない整備は、`09-brand-voice.md` の「誠実」に反し、差し戻し対象**です。

## 8. 検品を止めるべきサイン（即STOP条件）

1. 真贋がグレー
2. バッテリーが膨張している
3. 異臭・発熱・液漏れがある
4. リコール対象と判明した
5. PSE・技適など必要な表示がない
6. 許可が必要な商品と判明した（→ `law-checker`）
7. **説明文で正直に書いたら売れないと感じた**

7番は特に重要です。
「正直に書くと売れない」と感じた時点で、それは**売ってはいけない商品**です。

---

## 9. 検品完了後の引き継ぎ

```
検品完了 → `condition-grader` がランク確定
        → `refurb-cleaner`（整備の要否を判定）
        → `pricing-strategist`（ランクに応じた売価設計）
        → `description-copywriter`（状態記述をそのまま渡す）
        → `inventory-manager`（在庫台帳へランク付きで登録）
```

**`description-copywriter` に渡す状態記述は、検品記録を要約せず、
実測値をそのまま渡してください。**要約の過程で欠点が落ちるのが返品の原因です。
