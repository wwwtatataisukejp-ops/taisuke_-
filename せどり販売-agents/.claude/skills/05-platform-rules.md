# 05 販路別ルール・攻略マニュアル

> 参照：05出品・販売部 ／ `platform-policy-guard` ／ `fba-operator` ／ `platform-optimizer`

---

## ⚠️ このマニュアルの数値・規約について

**販路の手数料・仕様・規約は改定されます。**
本マニュアルは「**何を確認すべきか**」のチェックリストであり、
記載された数値・ルールを確定情報として扱ってはいけません。

```
必ず：出品前に各販路の公式ヘルプ・規約ページで現行のルールを確認する
出力に：「2026/07/27時点の公式規約を確認済み」または
        「【要検証】公式未確認」を必ず明記する
```

規約違反はアカウント停止＝**事業の即死**（CLAUDE.md 3大制約）です。
`platform-policy-guard` は、不明な点を「たぶん大丈夫」で通してはいけません。

## 1. 販路の選び方（`platform-optimizer` の判断軸）

| 軸 | 内容 |
|---|---|
| **手数料** | 成約時手数料・月額費用・決済手数料の合計 |
| **回転速度** | その商品カテゴリで最も早く売れる場所はどこか |
| **相場の高さ** | 同じ商品でも販路によって成約価格が異なる |
| **手間** | 出品作業・梱包・顧客対応の工数 |
| **リスク** | 返品条件・アカウント停止の厳しさ・詐欺の多さ |

### 販路選定の式
```
販路別の実質粗利 = 想定売価(販路別) − 仕入原価 − 手数料(販路別) − 送料 − 梱包費
実質時間単価     = 実質粗利 ÷ (出品〜発送〜対応にかかる時間)
```

**手数料が安い販路が常に正解ではありません。**
相場が高く早く売れる販路の方が、手数料が高くても勝つことが多くあります。

### カテゴリ別の一般的な傾向（自社実績で更新すること）
| カテゴリ | 相性の良い販路 | 理由 |
|---|---|---|
| 家電・型番商品 | Amazon | 型番指名検索が強い |
| ブランド衣類・雑貨 | メルカリ | 個人購買層が厚い |
| コレクター品・希少品 | ヤフオク! | 相場を知る層が競る |
| 大量・定番の新品 | Amazon（FBA） | 回転と自動化 |
| 日本限定品・アニメ関連 | eBay | 海外需要 |
| 大型・重量物 | 地域の掲示板／店舗 | 送料が利益を食う |

| 確認項目 | 記入欄 |
|---|---|
| 出品用アカウント種別（大口／小口） | |
| カテゴリ別の販売手数料率 | |

| FBA配送代行手数料（サイズ・重量区分） | |
| FBA在庫保管手数料（月額・長期保管） | |
| 出品制限カテゴリ・要申請ブランド | |
| 中古出品の可否（カテゴリによる） | |
| コンディションガイドラインの表記 | |
| 返品ポリシー（購入者都合の返品範囲） | |
| 真贋申立て（知的財産権）への対応手順 | |

**特に注意**
- **出品制限**：仕入前に「自分のアカウントで出品できるか」を確認する。
  出品できない商品を仕入れる事故が最も多い。
- **相乗り出品**：既存カタログに相乗りする際、**商品が完全一致しているか**を確認。
  型番違い・世代違いの相乗りは規約違反かつ返品原因。
- **カタログの改変**：他社が作ったカタログの情報を勝手に書き換えない。
- **真贋申立て**：申立てを受けたら**即座に社長へエスカレーション**（CLAUDE.md 第7章）。
  請求書等の証明書類の提出が必要になるため、**仕入時のレシート保管が必須**。

#### Amazon コンディション表記との対応（自社ランク → Amazon）
| 自社ランク | Amazon の中古コンディション（目安） |
|---|---|
| S | 新品 |
| A | ほぼ新品（Used - Like New） |
| B | 非常に良い（Used - Very Good） |
| C | 良い（Used - Good）／可（Acceptable） |
| D | 出品しない（不可） |

**必ず Amazon の公式コンディションガイドラインの定義文を読み、
自社ランクとズレがあれば「1つ下」を選んでください。**

## 3. 全販路 共通の禁止行為（アカウント防衛の赤線）

`platform-policy-guard` は、以下を発見したら**無条件で出品を止めます**。

1. **無在庫出品**（手元にない商品の出品）
2. **キーワードスパム**（無関係なブランド名・人気商品名の記載）
3. **他販路への誘導**（説明文に他サイト名やURLを書く）
4. **複数アカウントの規約違反的運用**
5. **カタログ・画像の不正利用**（他人の画像、メーカー画像の無断使用）
6. **偽ブランド品・権利侵害品の出品**
7. **許可が必要な商品の無許可出品**（医薬品・酒類・チケット等）
8. **虚偽の状態記載・欠点の意図的な省略**
9. **自作自演の評価・レビュー操作**
10. **取引を販路外で完結させる行為**（直接取引の誘導）

**これらは CLAUDE.md 6.4 の赤線と一致します。利益が出ても実行しません。**

## 4. アカウント警告を受けたときの手順（`platform-policy-guard` 主導）

```
① 即時：該当出品を停止する（判断を待たない）
② 即時：社長へ報告（CLAUDE.md 第7章のエスカレーション条件4）
③ 事実確認：何の規約の、どの条項に、どう抵触したか
④ 記録収集：仕入レシート、検品写真、出品内容のスクリーンショット
⑤ 原因分析：単発ミスか、運用上の構造問題か
⑥ 是正計画：同種の出品を全点検し、再発防止策を文書化
⑦ 申し立て：販路の指定手順に従い、事実と是正策を簡潔に提出
```

### 申し立て文の原則
- 感情的な反論を書かない
- **事実 → 原因 → 是正策 → 再発防止**の順で簡潔に
- 証拠書類（仕入レシート等）を添える
- 認めるべき非は明確に認める

**仕入レシートを保管していないと、この手順が実行できません。**
`bookkeeper` のレシート保管は、経理のためだけでなく**アカウント防衛のため**でもあります。

## 5. 販路変更の判断（滞留在庫リカバリー P3）

現在の販路で売れない場合、値下げの前に**販路変更**を検討します。

```
販路変更の判定：
  他販路の相場 − 他販路の手数料 − 追加の出品工数
    > 現販路で値下げした場合の粗利
      ↓ Yes なら販路変更
```

| 状況 | 推奨アクション |
|---|---|
| Amazonで出品者が多く価格競争 | メルカリ・ヤフオク!へ移動 |
| メルカリで反応がない専門性の高い品 | ヤフオク!（相場を知る層へ） |
| 国内需要が薄い日本限定品 | eBay（越境）を検討 |
| どの販路でも相場割れ | 損切り判断（`kpi-analyst` と協議） |

**販路を移す際は、出品文を必ず作り直す**（`platform-optimizer`）。
コピペによる文字数超過・禁止表現・他販路名の残存が事故になります。
