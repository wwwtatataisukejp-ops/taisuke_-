# 08 会計・税務

> 参照：07経理・財務部 全員

---

## ⚠️ 最重要の前提

**このマニュアルは税務助言ではありません。**
税制は改正され、個別の事情（所得区分・規模・法人／個人・課税事業者か否か）で
結論が大きく変わります。

```
このマニュアルの役割 = 「論点を漏れなく洗い出し、正しい記録を残すこと」
最終的な判断        = 税理士または所轄税務署に確認する
```

`tax-advisor` は、確定的な税額計算や申告方針の断定を行いません。
**論点の整理・必要な記録の提示・専門家に聞くべき質問の作成**が役割です。

## 1. せどりの会計で最も重要な原則

### 1.1 「仕入れた時点」では経費にならない

これが最大の誤解であり、**資金が黒字倒産を起こす原因**です。

```
❌ 誤り：100万円分仕入れたから、100万円が今期の経費
✅ 正しい：売れた分だけが「売上原価」として費用になる
          売れ残りは「棚卸資産（在庫）」として資産に残る
```

### 1.2 売上原価の計算式
```
売上原価 = 期首棚卸高 + 当期仕入高 − 期末棚卸高
利益     = 売上高 − 売上原価 − 販売経費 − その他経費
```

### 1.3 これが意味すること（`cashflow-planner` と共有）
```
現金がない × 在庫が多い = 利益は出ている（＝税金がかかる）
```

**「お金はないのに税金だけかかる」状態**が、在庫ビジネスの典型的な事故です。
だから CLAUDE.md は在庫比率70%を上限にしています。

`kpi-analyst` は月次レビューで、必ず
「**帳簿上の利益**」と「**手元現金の増減**」を**別々に**報告してください。

## 2. 勘定科目（せどりで使う主なもの）

| 区分 | 勘定科目 | 内容 |
|---|---|---|
| 収益 | 売上高 | 商品の販売額（**販売手数料を引く前の総額**が原則） |
| 費用 | 仕入高 | 商品の仕入代金 |
| 費用 | 荷造運賃 | 出荷送料、梱包資材費 |
| 費用 | 支払手数料 | 販売手数料、決済手数料、振込手数料 |
| 費用 | 広告宣伝費 | 販路内の広告 |
| 費用 | 消耗品費 | 事務用品、少額の備品 |
| 費用 | 旅費交通費 | 店舗仕入の交通費・駐車場代 |
| 費用 | 通信費 | 通信回線、携帯料金（**按分**） |
| 費用 | 地代家賃 | 倉庫・保管スペース（**按分**） |
| 費用 | 水道光熱費 | （**按分**） |
| 費用 | 外注費 | 業務委託（→ `outsourcing-designer`） |
| 費用 | 租税公課 | 事業に関する税・手数料 |
| 費用 | 減価償却費 | 高額な機材（PC・車両等） |
| 資産 | 棚卸資産（商品） | **売れ残った在庫** |

### 2.1 売上の計上について（要確認事項）
販売手数料が差し引かれて入金される場合、
「**手数料控除後の入金額**」ではなく「**販売総額**」を売上に計上し、
手数料を費用として別計上するのが原則的な処理とされます。

**具体的な処理は税理士に確認してください。**
どちらの方法でも利益は同じですが、売上規模の把握と消費税の判定に影響します。

### 2.2 家事按分（自宅で事業を行う場合）
自宅の家賃・光熱費・通信費のうち、**事業に使っている割合だけ**を経費にします。

```
按分の根拠を必ず記録する
  例：作業スペース 6畳 ÷ 総床面積 60畳 = 10% → 家賃の10%を計上
  例：事業使用時間 100時間 ÷ 月間 720時間 = 13.9%
```

**根拠のない按分割合は否認されるリスクがあります。**
計算根拠をメモに残してください。

## 3. 記帳の実務（`bookkeeper` 用）

### 3.1 記帳の3原則
1. **毎日または毎週、必ず処理する**（月末にまとめる運用は必ず破綻する）
2. **在庫台帳（`06-logistics-ops.md`）と管理番号で紐付ける**
3. **証憑（レシート・請求書・取引画面）を必ず保存する**

### 3.2 証憑の保存
| 証憑 | 保存理由 |
|---|---|
| 仕入レシート・領収書 | 経費の証明／**真贋申立て時の反証**（→ `07-legal-compliance.md`） |
| 販路の売上明細 | 売上の証明 |
| 送料の明細 | 経費の証明 |
| 交通費の記録 | 経費の証明（日付・行先・目的を記録） |
| 検品・梱包写真 | トラブル対応（→ `03-product-inspection.md`） |

**保存期間は法令で定められています。所轄税務署または税理士に確認してください。**

> 実務メモ：レシートは仕入日に撮影して
> `receipts/YYYYMM/YYYYMMDD_店名_金額.jpg` で保存すると、
> 在庫台帳の管理番号と突き合わせやすくなります。

### 3.3 現金仕入の記録（店舗せどりの弱点）
店舗仕入は現金・レシートのみになりがちで、**記帳漏れが最も起きやすい**領域です。
```
対策：
  ① 仕入直後にレシートを撮影する（その場で）
  ② 在庫台帳に「仕入先」列を必ず埋める
  ③ 事業用の決済手段を分ける（可能なら事業用カード・口座）
```

### 3.4 事業用と私用の分離
口座・カードを私用と分けることで、記帳と按分の手間が劇的に減ります。
分けていない場合、**すべての取引を1件ずつ仕分ける作業が発生**します。

## 4. 棚卸（`inventory-manager` と共同）

### 4.1 棚卸のタイミング
- **期末（決算日）には必須**
- 実務上は**毎月**行うことを推奨（`06-logistics-ops.md` 第8章）

### 4.2 棚卸資産の評価
在庫の評価方法にはいくつかの方法があり、**選定した方法を継続適用**するのが原則です。
どの評価方法を採用するか、届出が必要かは**税理士または税務署に確認**してください。

### 4.3 価値が下がった在庫の扱い（要確認）
相場が下落して仕入原価を割った在庫について、
評価を下げられるかどうかは**要件があり、個別判断**になります。

```
`tax-advisor` の対応：
  ・「評価損を計上できます」とは断定しない
  ・どの在庫が、いつから、いくら下落しているかを**記録として整理**する
  ・その資料を持って税理士に相談することを提案する
```

### 4.4 廃棄・損切りの記録
| 状況 | 残すべき記録 |
|---|---|
| 廃棄 | 廃棄日、品目、数量、取得原価、**廃棄した理由**、可能なら写真 |
| 損切り販売 | 売却日、売却額、取得原価、差額 |
| 返品による損失 | 返品日、返金額、再販可否 |

記録のない廃棄は、経費として認められないリスクがあります。

## 5. 消費税の論点（`tax-advisor` 用・要確認）

### 5.1 押さえるべき論点
| 論点 | 内容 |
|---|---|
| 課税事業者か免税事業者か | 判定基準（基準期間の課税売上高等）を確認 |
| インボイス制度（適格請求書） | 登録の要否、登録した場合の影響 |
| 仕入税額控除 | どの仕入について控除できるか |
| 古物商特例 | 古物商が消費者から買い取る場合の取扱い（**要確認**） |
| 簡易課税・2割特例等 | 適用可否・有利不利の判定 |
| 輸出・輸入 | 越境取引の消費税の取扱い |

### 5.2 `tax-advisor` の姿勢
**消費税は制度が複雑で、判断を誤ると多額の負担が生じます。**
以下は断定してはいけません。

- 「課税事業者になるべきです／ならない方が得です」
- 「インボイス登録は不要です」
- 「この仕入は仕入税額控除できます」

代わりに出力すべきもの：
```
【論点整理】
・現在の課税売上高：¥◯◯◯（2025年度実績）
・インボイス登録：未登録
・取引先の状況：法人向け販売の比率 ◯%

【税理士に確認すべき質問】
1. 当社は次年度に課税事業者となるか
2. インボイス登録の有無で、当社の販路構成ではどちらが有利か
3. 消費者からの買取に古物商特例は適用できるか

【判断に必要な資料】
・直近2期の売上高、販路別の売上構成、仕入先の区分
```

## 6. 確定申告・事業形態の論点（要確認）

### 6.1 押さえるべき論点
| 論点 | 確認すべきこと |
|---|---|
| 開業届 | 提出済みか |
| 所得区分 | 事業所得か雑所得か（規模・継続性・帳簿の有無等で判断） |
| 青色申告 | 承認申請の有無、適用要件（帳簿要件等） |
| 帳簿の記帳方法 | 複式簿記か簡易簿記か |
| 減価償却 | 高額な機材の処理 |
| 専従者給与 | 家族に手伝ってもらう場合 |
| 会社員の副業 | 住民税の扱い、勤務先の規定 |
| 法人化 | 利益水準、社会保険、消費税への影響 |

### 6.2 事業所得と雑所得
どちらに区分されるかで、損益通算・青色申告の適用などが変わります。
**帳簿書類の保存が判断要素になるとされています。**
→ 本マニュアルの記帳ルールを守ること自体が、この論点への備えになります。

**最終的な区分の判断は税理士に確認してください。**

## 7. 資金繰り（`cashflow-planner` 用）

### 7.1 資金繰り表（毎月更新）
| 項目 | 今月 | 来月 | 再来月 |
|---|---|---|---|
| 月初現金残高 | | | |
| ＋ 販路からの入金（販路別・入金日別） | | | |
| ＋ その他収入 | | | |
| − 仕入支出（現金） | | | |
| − クレジットカード引落 | | | |
| − 固定費（家賃・通信・倉庫） | | | |
| − 販売経費（送料・資材） | | | |
| − 外注費 | | | |
| − 税金・社会保険 | | | |
| **＝ 月末現金残高** | | | |
| 在庫評価額 | | | |
| **在庫比率（在庫 ÷ (現金+在庫)）** | | | |

### 7.2 入金サイクルの把握（最重要）
販路ごとに**売却から入金までの日数が違います**。
```
売却 → 入金 の日数を販路別に記録する

例：
  販路A：締め日 + ◯日後に入金
  販路B：申請から◯営業日
  販路C：即時／◯日後
```

**カードの引落日が、販路の入金日より先に来るとショートします。**
`cashflow-planner` は、この2つのカレンダーを必ず並べて管理してください。

### 7.3 仕入予算の決め方
```
今月の仕入可能額 = 手元現金
                 − 翌月末までの固定費
                 − 翌月末までのカード引落
                 − 安全余裕（月商の20%を目安）
```

さらに `00-sedori-basics.md` の在庫比率70%の制約を満たすこと。
**どちらか厳しい方を上限**とします。

### 7.4 クレジットカード仕入の危険性
| メリット | リスク |
|---|---|
| 手元現金がなくても仕入できる | **売れなくても支払日は来る** |
| ポイント還元 | 支払サイクルを誤ると連鎖的にショートする |
| 支払サイクルを稼げる | 与信枠を使い切ると仕入が止まる |

**カード枠を「資金」と考えてはいけません。** カード枠は**負債**です。
`cashflow-planner` は、カード利用残高を必ず負債として資金繰り表に載せてください。

### 7.5 資金の危険信号（即エスカレーション）
1. 在庫比率が70%を超えた（CLAUDE.md 第7章 条件6）
2. 翌月のカード引落額 > 翌月の入金見込額
3. 滞留在庫（90日超）が在庫額の10%を超えた
4. 現金残高が固定費1ヶ月分を下回った

## 8. 月次クローズの手順（毎月1回）

```
① 全在庫の棚卸（`inventory-manager`）
② 在庫評価額の確定
③ 売上の集計（販路別）
④ 仕入・経費の記帳完了、証憑の突合
⑤ 売上原価の算出（期首 + 仕入 − 期末）
⑥ 月次損益の確定（`bookkeeper`）
⑦ 資金繰り表の更新（`cashflow-planner`）
⑧ KPIの算出（`kpi-analyst`）
⑨ 月次レビュー（P5 パイプライン）
```

### 月次で必ず並べて見る2つの数字
| | 今月 |
|---|---|
| 帳簿上の利益 | ¥ |
| 現金の増減 | ¥ |
| 差額の理由（在庫増／カード未払／入金待ち） | |

**この2つが乖離していることに気づかないのが、最も危険な状態**です。

## 9. `tax-advisor` の出力フォーマット

```
【結論】論点あり。税理士への確認を推奨します。

【整理した事実】
・当期の課税売上高：¥◯◯◯（2026/01〜06 実績）
・期末在庫評価額：¥◯◯◯（2026/06/30 棚卸）
・インボイス登録：未登録

【論点】
1. 次年度の課税事業者判定
2. 古物商特例の適用可否

【税理士に聞くべき質問】
1. （具体的な質問文）
2. （具体的な質問文）

【準備すべき資料】
・（資料名）

【この回答の限界】
・本回答は税務助言ではありません。最終判断は税理士または所轄税務署にご確認ください。
```
