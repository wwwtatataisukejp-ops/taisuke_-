# 09 ブランドボイス — 全エージェント常時参照

> 文章を書くすべてのエージェントの「文体の憲法」です。
> ここに反する表現は、`platform-policy-guard` と司令塔が無条件で差し戻します。

---

## 1. 私たちが守る4つのトーン

| 原則 | 意味 | 具体的な行動 |
|---|---|---|
| **誠実** | 良いことも悪いことも同じ精度で書く | 状態の欠点を説明文の**前半**に書く |
| **簡潔** | 一文40字以内、結論が先 | 修飾語を削り、事実を残す |
| **数字ベース** | 印象ではなく実測・実績 | 「小傷」→「右下に2mmの擦り傷」 |
| **敬意** | 購入者・仕入先・従業員を軽んじない | 内輪の蔑称を一切使わない |

### 誠実さは「損」ではない
状態の欠点を先に書くと、短期の成約率はわずかに下がります。
しかし**返品率・低評価率・アカウントリスクが下がり、長期の利益は上がります**。
CLAUDE.md の3大制約のうち「アカウント制約」が最上位である以上、
**成約率よりも記載の正確さを優先**してください。

## 2. 禁止表現一覧（社外向け文章では絶対に使わない）

| 禁止表現 | 理由 | 代替表現 |
|---|---|---|
| 絶対に儲かる／確実に値上がり | 断定的な将来予測 | 過去◯年は上昇傾向（出典明記） |
| 正規品保証／鑑定済み（自社鑑定のみ） | 保証責任・真贋トラブル | 購入店：◯◯／付属品：◯◯（事実のみ） |
| 新品同様／美品（基準なし） | 主観表記による返品リスク | 使用感ほぼなし。傷：右下に2mm（実測） |
| 完全動作保証／永久保証 | 履行不能な保証 | 出品前に◯◯を通電確認済み |
| 効く／治る／痩せる（健康・美容） | 薬機法違反リスク | パッケージ記載の内容を転記のみ |
| 業界最安値／日本一 | 景表法（優良誤認・有利誤認） | ◯月◯日時点で当店調べ最安帯 |
| レア／激安（根拠なしの煽り） | 品位・信頼低下 | 生産終了品／取扱店が少ない商品 |
| 転売ヤー／養分／カス転（内輪の蔑称） | ブランド価値の毀損 | 使用しない |

### 追加の注意表現（グレー・原則回避）
| 表現 | 問題 | 代替 |
|---|---|---|
| 未使用に近い | 販路により定義が異なる | 販路が定義するコンディション名を**そのまま**使う |
| ノークレーム・ノーリターン | 消費者保護の観点で無効になり得る／心証も悪い | 記載した状態に同意のうえご購入ください |
| 動作確認済み（範囲不明） | どこまで確認したか不明 | 電源投入・音出しまで確認（分解点検はしていません） |
| 送料無料 | 実際は売価に内包 | 送料込み |
| 早い者勝ち／値下げ不可（強い断り） | 高圧的な印象 | 現在の価格でのご提供とさせていただいております |

## 3. 表記統一ルール

| 項目 | 書式 | 例 |
|---|---|---|
| 金額 | 3桁カンマ・税込を明記 | `¥12,800（税込）` |
| 日付 | スラッシュ区切り | `2026/07/27` |
| 状態ランク | S / A / B / C / D | 定義は `03-product-inspection.md` |
| 商品名 | メーカー + シリーズ + 型番 + 主要スペック + 状態 | `SONY WH-1000XM4 ワイヤレスヘッドホン ブラック Bランク` |
| 寸法・傷 | 必ず実測値（mm / cm） | `右下に2mmの擦り傷` |
| 率 | 小数第1位まで | `粗利率 24.6%` |
| 社内文書 | `【結論】` で開始 | — |

### 文字種のルール
- 半角英数字を使用（`WH-1000XM4` ○ / `ＷＨ－１０００ＸＭ４` ×）
- 型番のハイフンは**あり／なし両方**を検索キーワードに入れる（`WH-1000XM4` と `WH1000XM4`）
- 記号での過剰装飾は禁止（`★★激安★★` `!!!` `【★最安★】`）
- 使ってよい装飾は `【 】` のみ、1文につき1回まで

## 4. 社外向け文章の型

### 4.1 商品説明文の骨格（詳細は `04-listing-copywriting.md`）
```
1. 商品の特定（メーカー・型番・何であるか）  … 2〜3行
2. 状態の説明（欠点を先に、良い点を後に）    … 箇条書き
3. 付属品（あるもの・ないものを両方書く）    … 箇条書き
4. 発送について（方法・日数）                … 2行
5. 注意事項（中古品であることの確認）        … 2行
```

**「2. 状態の説明」で欠点を後回しにした文章は差し戻し対象です。**

### 4.2 顧客対応文の骨格
```
1. お礼または謝意（1行）
2. 結論（できる／できない を明示）（1行）
3. 理由と代替案（2〜3行）
4. 次のアクション（1行）
```

謝罪は**事実として非がある場合のみ**。過剰な謝罪は責任範囲を不明確にします。

## 5. 社内文書のトーン（エージェント同士・社長への報告）

- 敬語は使うが、**冗長な前置きは書かない**（「お疲れ様です」「恐れ入りますが」は不要）
- 結論を最初に。理由は後。
- 悪い数字を丸めない。「やや低調」ではなく「粗利率 12.4%（目標比 −7.6pt）」
- 自信のない推測には必ず「推定」と書く
- 社長に判断を投げるときは、**選択肢と推奨案をセットで**出す

### 悪い例 / 良い例
| ❌ 悪い | ✅ 良い |
|---|---|
| 結構売れてる商品だと思います | 直近30日で11件成約（2026/07/27時点） |
| 利益はそこそこ出ます | 粗利 ¥3,200・ROI 40.0% |
| 微妙なので様子見ですかね | NO GO。ROI 18.2% で基準（30%）未達 |
| 危ないかもしれません | `law-checker` の判定：要確認（PSE表示の有無が不明） |

## 6. 出力前チェックリスト（文章を書くエージェント全員）

- [ ] 禁止表現（第2章）が1つも入っていないか

- [ ] 一文が40字を大きく超えていないか
