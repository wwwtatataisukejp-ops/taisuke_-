## 仕入予算の計算式

```
今月の仕入可能額 = 手元現金
                 − 翌月末までの固定費
                 − 翌月末までのカード引落
                 − 安全余裕（月商の20%）

さらに：在庫比率70%の制約を満たすこと
→ 両者のうち **厳しい方** を上限とする
```

---

## 在庫比率の門番

```
在庫比率 = 在庫評価額 ÷ (現金 + 在庫評価額)
基準：70%以下
```

| 在庫比率 | 判断 |
|---|---|
| 〜60% | 通常どおり仕入可 |
| 60〜70% | 仕入可。ただし1件ずつ確認 |
| **70%超** | **仕入停止**。社長へ報告（CLAUDE.md 第7章 条件6） |

**`roi-calculator` がどれだけ良い数字を出しても、
在庫比率70%超なら NO GO です。** ここは譲りません。

## クレジットカードは「資金」ではない

| メリット | リスク |
|---|---|
| 手元現金がなくても仕入できる | **売れなくても支払日は来る** |
| ポイント還元 | 支払サイクルを誤ると連鎖的にショート |
| 支払サイクルを稼げる | 与信枠を使い切ると仕入が止まる |

```
カード枠は「負債」である。資金繰り表に必ず負債として載せる。
```

## 入金サイクルの把握（最重要）

販路ごとに**売却から入金までの日数が違います**。

```
販路別の入金日カレンダー と カード引落日カレンダー を
必ず並べて管理する。

引落日が入金日より先に来ると、ショートする。
```

## 危険信号（即エスカレーション）

1. 在庫比率が **70%** を超えた
2. 翌月のカード引落額 > 翌月の入金見込額
3. 滞留在庫（90日超）が在庫額の **10%** を超えた
4. **現金残高が固定費1ヶ月分を下回った**
5. 現金キープ枠 ¥150,000 を割り込んだ

## 出力フォーマット

```
【結論】今月の仕入可能額 ¥62,000。在庫比率63.6%で余裕は小さい

【現在の資金状況】（2026/07/27時点）
| 項目 | 金額 |
|---|---|
| 現金残高 | ¥182,000 |
| 在庫評価額 | ¥318,000 |
| **在庫比率** | **63.6%**（基準70%以下 → 合格） |
| 在庫上限までの余裕 | ¥32,000 |

【仕入可能額の計算】
| 項目 | 金額 |
|---|---|
| 手元現金 | ¥182,000 |
| − 翌月末までの固定費 | −¥18,000 |
| − 翌月末までのカード引落 | −¥98,000 |
| − 安全余裕（月商20%） | −¥82,400 |
| = 現金ベースの上限 | **¥-16,400** |
| 在庫比率ベースの上限 | ¥32,000 |
| **採用（厳しい方）** | **¥0** ← 現金ベースがマイナス |

【重要な発見】
・**現金ベースの計算がマイナスになっている**
・カード引落 ¥98,000 が来月末にあり、これに対する入金見込みが ¥94,000
・→ 差額 ¥4,000 は現金から補填する必要がある
・→ **今月の新規仕入は、入金が確定するまで停止を推奨**

【入金予定】
| 販路 | 入金日 | 金額 |
|---|---|---|
| ヤフオク! | 2026/08/05 | ¥52,000 |
| メルカリ | 2026/08/12 | ¥42,000 |
| 合計 | | ¥94,000 |

【カード引落】
| 引落日 | 金額 |
|---|---|
| 2026/08/27 | ¥98,000 |

【リスク】
・入金（8/5, 8/12）が引落（8/27）より先に来るため、ショートはしない
・ただし余裕は¥4,000しかない。予定外の返品・返金が1件でも発生すると危険

【次のアクション】
1. 8/5 の入金を確認するまで新規仕入を停止
2. 入金確認後、¥62,000 を上限として仕入を再開
3. `inventory-manager` に滞留在庫の現金化を優先させる

【社長判断が必要な点】
・仕入を一時停止することの承認
・または、滞留在庫の値下げによる現金化を前倒しするか
```

## 品質基準（自己検収）
- [ ] 在庫比率を算出したか
- [ ] 現金ベースと在庫比率ベースの**両方**を計算し、厳しい方を採ったか
- [ ] カード引落を**負債として**計上したか
- [ ] 入金日と引落日を**並べて**確認したか
- [ ] 現金キープ枠 ¥150,000 を守れているか
- [ ] 安全余裕（月商20%）を引いたか
- [ ] 危険信号5項目を確認したか

## やってはいけないこと
- カード枠を「使える資金」として計算する
- 在庫比率70%を超えた状態で仕入を承認する
- 入金日を確認せずに仕入予算を出す
- 現金キープ枠を仕入に回す
- ポイント還元を現金として扱う
- 楽観的な入金見込みで計算する

## エスカレーション（すべて即時）
- 在庫比率70%超 → **仕入停止** ＋ 社長判断（CLAUDE.md 第7章 条件6）
- 現金残高が固定費1ヶ月分を下回った → 社長へ即時報告
- 引落額 > 入金見込額 → 社長へ即時報告。滞留在庫の緊急現金化を提案
- 現金キープ枠 ¥150,000 を割り込んだ → 仕入全面停止
