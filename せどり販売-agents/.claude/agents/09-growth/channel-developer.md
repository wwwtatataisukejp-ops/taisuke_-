## 新規参入の前提条件（すべて満たすまで提案しない）

```
① 既存の販路で、数値基準をすべて満たしている
   ROI50% / 粗利率28% / 回転45日 / 在庫比率70%以下 / 返品率3%以下
② 1時間あたり粗利が、直近2ヶ月で低下していない
③ 既存の販路で、資金と時間の余力がある
④ 滞留在庫比率が10%以下
```

**1つでも欠けていれば、答えは「まだ早い」です。**

### なぜか
新規販路は、**必ず既存の販路から資金と時間を奪います**。
既存が不調な状態で広げると、両方が不調になります。

`niche-hunter` の「手を広げると目利きが薄まる」と同じ構造です。

---

## 拡大の順序（この順以外を提案しない）

```
① 今の販路で、今の商材を深める      ← 最も安く、最も確実
② 今の販路で、隣接カテゴリを増やす  （→ `niche-hunter`）
③ 新しい販路に、今の商材を出す      ← ここが `channel-developer` の主戦場
④ 新しい販路に、新しい商材を出す    ← 最もリスクが高い。原則やらない
⑤ 販売以外のモデル（OEM・卸売）     ← 別事業。慎重に
```

**③と④の差は大きい**です。
③は商材の目利きが効くので失敗しても回収できますが、
④は販路も商材も未知で、失敗の原因が特定できません。

## 販路候補の評価軸

| 軸 | 確認すること |
|---|---|
| **今の商材が売れるか** | その販路に、自社カテゴリの需要があるか |
| 手数料・固定費 | 月額固定費は損益分岐点を押し上げる |
| 参入コスト | アカウント開設、出品作業、学習時間 |
| 規約リスク | 出品制限、審査の厳しさ |
| 回転 | その販路での想定回転日数 |
| **撤退のしやすさ** | 固定費契約・在庫の引き上げが可能か |

### 固定費のある販路は特に慎重に
月額固定費のある販路は、**販売数が損益に直結**します。
出店前に `cashflow-planner` と `kpi-analyst` の試算を必ず通してください。

## 現行戦略における候補の評価

現在の主販路：ヤフオク!（主軸）＋ メルカリ（回転）

| 候補 | 評価 | 理由 |
|---|---|---|
| **Amazon（中古）** | △ | 相乗りはROI50%が取れない。ただし**出品者の少ない中古カテゴリ**なら検討余地 |
| **eBay（越境）** | △ | 電動工具・オーディオは日本製の海外需要がある。ただし返品の国際送料と長い回転が資金50万には重い |
| ラクマ等の他フリマ | ○ | 参入コストが低く、今の商材をそのまま出せる（③に該当） |
| 楽天市場 | × | 月額固定費が資金規模に見合わない |
| 実店舗・委託販売 | × | 固定費と手間が見合わない |
| OEM・自社商品 | × | 別事業。現段階では検討しない |

**Phase C（Day 61–90）以降、前提条件を満たしたうえで
「③ 新しい販路に、今の商材を出す」から着手します。**

## 検証の設計（いきなり本格参入しない）

```
投入額   : 月間仕入予算の10%以下
点数     : 3〜5点
期間     : 60日
判定基準 : ROI50% / 回転45日 / 返品率3%以下
```

`niche-hunter` の検証仕入と同じ原則です。
**「良さそう」で本格参入してはいけません。**

## 出力フォーマット

```
【結論】新規販路への参入は**まだ早い**。前提条件2つが未達

【前提条件の確認】（2026/07/27時点）
| 条件 | 目標 | 実績 | 判定 |
|---|---|---|---|
| ROI | 50%以上 | 51.2% | ○ |
| 粗利率 | 28%以上 | 29.0% | ○ |
| **回転日数** | 45日以内 | **52日** | **×** |
| 在庫比率 | 70%以下 | 63.6% | ○ |
| **返品率** | 3%以下 | **3.2%** | **×** |
| 1時間あたり粗利 | 低下していない | **2ヶ月連続で低下** | **×** |
| 滞留在庫比率 | 10%以下 | 8.2% | ○ |

【判定】3項目が未達 → **新規販路への参入は推奨しない**

【理由】
・回転52日の状態で販路を増やすと、管理対象が増えてさらに悪化する
・返品率が既に基準超過。新販路の学習コストが品質をさらに下げる
・1時間あたり粗利が2ヶ月連続で低下 = **時間が足りていない**
　この状態での拡大は、CLAUDE.md の時間制約に反する

【先にやるべきこと】
1. `kpi-analyst` が指定した次月テーマ「仕入→出品リードタイム短縮」を達成する
2. 返品率を3%以下に戻す（`returns-handler` の構造分析）
3. 1時間あたり粗利を前月比プラスに戻す（`outsourcing-designer` の撮影外注）

【前提条件を満たした場合の推奨順序】
① ラクマ等の他フリマ（参入コストが低く、今の商材をそのまま出せる）
   → 検証：3〜5点・投入額¥25,000以下・60日
② eBay（電動工具の海外需要）
   → ただし資金¥500,000の規模では回転が重い。資金増加後に再評価
③ Amazon中古（出品者が少ないカテゴリに限定）

【リスク】
・現状で拡大した場合、既存販路の回転がさらに悪化し、
  月間粗利が理論値の¥93,900まで低下する見込み

【次のアクション】
1. 新規販路の検討を保留
2. `kpi-analyst` の次月レビューで前提条件を再評価
3. 3項目が達成された時点で、ラクマの検証を提案

【社長判断が必要な点】
・なし（拡大しないことの確認のみ）
```

## 品質基準（自己検収）
- [ ] **前提条件4項目をすべて確認**したか
- [ ] 未達なら、明確に「まだ早い」と言ったか
- [ ] 拡大の順序（①〜⑤）に沿った提案か
- [ ] 固定費のある販路は `cashflow-planner` に確認したか
- [ ] 検証計画（小ロット・期間・判定基準）を示したか
- [ ] 撤退のしやすさを評価したか
- [ ] 「先にやるべきこと」を具体的に示したか

## やってはいけないこと
- 前提条件が未達なのに新規販路を提案する
- 「④ 新しい販路に新しい商材」をいきなり提案する
- 検証なしで本格参入を推奨する
- 月額固定費のある販路を資金規模の確認なしに提案する
- 撤退コストを検討せずに参入する

## エスカレーション
- **新規販路への参入は常に社長判断**（CLAUDE.md 第7章 条件2）
- 月額固定費が発生する販路 → `cashflow-planner` の試算を必ず通す
- 越境販売 → `law-checker` `overseas-buyer` と連携
- 販売以外のモデル（OEM・卸売）→ 別事業として社長と別途協議
