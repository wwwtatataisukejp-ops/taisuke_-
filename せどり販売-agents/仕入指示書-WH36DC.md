## 1. 枝番の見分け方（現場で最初に見ること）

WH36DC は**枝番で中身が全く違います**。ここを間違えると損失が確定します。

|---|---|
| **WH36DC(NN)** | **本体のみ**（バッテリ・充電器・ケース別売） |
| WH36DC(NNB) | 本体のみ（Bluetooth仕様） |
| **WH36DC(2XP)** | **本体 ＋ BSL36A18 ×2 ＋ 充電器 UC18YDL2 ＋ ケース** |
| WH36DC(2XPS) / (2XPGS) | 上記の Bluetooth仕様 |

### 色の識別（型番末尾）
`(B)`ストロングブラック ／ `(G)`フォレストグリーン ／ `(L)`アグレッシブグリーン ／ `(R)`フレアレッド

**色によって新品価格が違います**（後述）。相場も色で変わる可能性があるため、
色まで含めて記録してください。

### 現場での確認順序
```
① 本体の銘板で「WH36DC」を確認（WH36DD / WH18DC は別物）
② ケースを開けて、バッテリーが何個あるか数える
③ 充電器があるか
④ 値札が「本体のみ」の想定か「セット」の想定か
   → ここに食い違いがあれば、それが利益
```

## 4. どこで買うか（優先順位つき）

### ★最重要の原則
```
工具専門の買取店から仕入れても、利益は出にくい。
彼らはプロで、相場を知っている。

狙うべきは「工具の目利きがない店」。
そこにしか情報差は残っていない。
```

### 優先度1：一般リサイクルショップ（**最も狙い目**）
| 特徴 | 内容 |
|---|---|
| なぜ狙い目か | 工具の枝番・年式による価格差を把握していない。セット品が本体のみの値札で出る |
| 見る棚 | 工具コーナー、ジャンクコーナー、入荷直後の未整理棚 |
| 狙う時間 | 開店直後 |
| 注意 | 動作未確認品が多い。通電確認を必ず求める |

対象：セカンドストリート、各地のリサイクルショップ、
ハードオフの**通常店舗**（工具専門コーナーではない方）

### 優先度2：ハードオフ「工具館」
[工具館（ハードオフグループ）](https://www.hardoff.co.jp/shop/brand/kougukan/) — 工具に特化した買取・販売店。
```
中古在庫が確実にある反面、専門店なので値付けが的確。
→ 相場を学ぶ場としては最良。仕入れられれば儲け物、という位置づけ。
```

### 優先度3：工具中古の専門店
- [アクトツール](https://act-kougu.com/) — 中古工具の買取販売専門。店頭あり
- [エコツール](https://www.ecotool.jp/)（愛知・名古屋）

```
在庫の質は高いが、値付けもプロ。
「相場の57%以下」で出ていることは稀。
→ 定期的に見て、値下げ品・訳あり品だけを狙う。
```

### 優先度4：電脳仕入（条件付き）
| 仕入先 | 可否 | 条件 |
|---|---|---|
| **メルカリ** | 可 | **検品完了まで受取評価を押さない**（`online-sourcer` 参照） |
| ヤフオク! **ストア出品** | 可 | 落札後30日の保証がある |
| **ヤフオク! 個人出品** | **セット品は不可** | 同梱バッテリーの真贋を事前確認できず、偽物の補償もない |

**本体のみ(NN)であれば、ヤフオク!個人出品も検討可**（バッテリーが付かないため）。

### 買取専門店は「相場の教科書」として使う
[工具買取王国](https://kougu-okoku.jp/)、[電動工具高く売れるドットコム](https://www.kougu-takakuureru.com/)、
[買蔵](https://tool-land.com/) などの**買取価格表**は、
「プロがいくらで買うか」＝**相場の下限の目安**として使えます。

```
買取店の買取価格 ＜ 自社の上限仕入値 なら、勝負できる可能性がある
買取店の買取価格 ＞ 自社の上限仕入値 なら、プロより高く買うことになる → 見送り
```

## 5. 現場チェックリスト（1商品90秒）

```
■ 枝番（最初に確認）
  □ WH36DC であることを銘板で確認（WH36DD / WH18DC ではない）
  □ 枝番：(NN)本体のみ / (2XP)セット のどちらか
  □ 色：(B)(G)(L)(R) のどれか

■ 中身の実物確認
  □ バッテリーの個数を数えた
  □ 充電器の有無を確認した
  □ ケースの有無を確認した

■ 価格
  □ 値札 ≦ 上限仕入値（本体のみ¥4,930 / セット¥7,273）
  □ 買取店の買取価格を上回っていないか

■ 動作（`condition-grader` の範囲で）
  □ 通電する（店で確認を依頼）
  □ 正転・逆転・変速が動く
  □ 異音・異臭がない

■ セット品の場合（追加・必須）
  □ 同梱バッテリーの真贋を確認できるか
    純正約660g級の重量／樹脂の艶／ロゴ／日本語表記
    → `authenticity-checker` の判定基準を適用
  □ バッテリーが膨張していないか
  □ 判定できなければ **セットごと見送る**

■ 赤線
  □ 模造バッテリーの疑いがない
  □ 状態を正直に書いても売れる商品か
```

## 6. 買ってはいけない条件（1つでも該当したら見送り）

1. 枝番が読めない／確認できない
2. ケースを開けさせてもらえない（中身が確認できない）
3. 値札が上限仕入値を超えている（**1円でも超えたら見送り**）
4. 同梱バッテリーの真贋を判定できない
5. バッテリーが膨張している
6. 通電確認をさせてもらえない
7. 相場より極端に安く、その理由が説明できない
8. **セット相場の中央値が未確定のまま、楽観値(¥12,748)で判断しようとしている**

## 8. 仕入後の流れ

```
仕入 → `condition-grader`（検品・ランク確定）
     → セット品なら `authenticity-checker`（バッテリー全個体を重量実測）
     → `pricing-strategist`（枝番別の売価設計）
     → `platform-optimizer`（ヤフオク!主軸）
     → `title-keyword-writer`（**枝番と付属品をタイトルに必ず入れる**）
     → `photo-director` → `description-copywriter`
     → `platform-policy-guard`（最終検収）
     → `inventory-manager`（台帳登録）／`bookkeeper`（レシート保管）
```

**出品タイトルには必ず枝番と付属品を入れます。**
