## ⚠️ 最初に：この数字の性質（必読）

**相場は取得できました。ただし取得できたのは「平均落札価格」です。**

```
当社の判定基準は「中央値」（`01-sourcing-playbook.md` 第2章）。
本リストの数字は「平均値」であり、判定基準ではありません。

平均値が使えない理由：
  マキタ BL1860B の落札分布 = 最安 1円 / 最高 263,761円 / 平均 14,965円
  → 1円スタートの部品取りと、業務用まとめ売りが同じ平均に混ざっている
```

| このリストの数字の使い道 | 使ってはいけない用途 |
|---|---|
| ✅ **どの型番から手を付けるかの優先順位付け** | ❌ GO/NO GO の判定根拠 |
| ✅ 上限仕入値の**目安**（現場での一次足切り） | ❌ 提案書に載せる「相場」 |
| ✅ 流動性（月間何件売れるか）の把握 | ❌ 粗利・ROIの確定計算 |

**提案書に載せる相場は、チームが第4章の手順で中央値を取り直したものだけです。**

## 1. 社長の役割（これだけ）

```
社長がやること   : 仕入提案書を見て「GO」または「NO GO」と言う
社長がやらないこと: 商品探し、相場調べ、計算、出品文作成、価格改定
```

### 社長に上げてよい提案書の条件（1つでも欠けたら上げない）
- [ ] 相場が**売却実績の中央値**で取得済み（出品価格ではない）
- [ ] 直近30日の成約件数が**4件以上**
- [ ] 出品者数を実数でカウント済み
- [ ] 上限仕入値（相場×0.57）を計算済み
- [ ] 実際の仕入可能価格が上限以下
- [ ] `law-checker` の判定が「問題なし」
- [ ] `cashflow-planner` の予算枠内
- [ ] 最悪シナリオ（相場20%下落・売れ残り）を計算済み

**条件を満たさない候補は、チーム内で握りつぶします。**
社長の時間を「判断できない案件」に使わせないことが、この仕組みの目的です。

## 4. 相場の取得手順（チームが実行する）

### 4.1 データ源（検証済み・2026/07/27）

| 源 | URL パターン | 取れるもの |
|---|---|---|
| **ヤフオク! 落札相場** | `https://auctions.yahoo.co.jp/closedsearch/closedsearch/<型番>/0/` | 落札実績の一覧・価格・件数 |
| **オークファン** | `https://aucfan.com/search1/q-<型番>/s-ya/` | **直近30日の落札件数・平均**、期間別推移 |
| オークファン（横断） | `https://aucfan.com/search1/q-<型番>/s-mix` | ヤフオク!＋メルカリ＋Amazon の横断相場 |

**オークファンの「直近30日の落札件数」が、当社の回転判定に最も有用**です。
`demand-forecaster` の計算式に直接投入できます。

### 4.2 取得の実務メモ（重要）

```
・ブラウザで開けば見られる（人が見る分には問題ない）
・プログラムからの自動取得は 403 で拒否される
  → 自動化しようとしないこと。`automation-architect` は
    「自動スクレイピングは対象外」として設計すること
・したがって相場取得は「人が開いて転記する」作業になる
  → `outsourcing-designer` の外注候補（判断を含まない作業）
```

### 4.3 手順（`01-sourcing-playbook.md` 第2章に準拠）

```
① 型番で完全一致検索する
   ★ 枝番まで含めて検索する（後述 4.4）
② **売却済みの実績だけ**を抽出する（出品中の価格は相場ではない）
③ 直近30日に絞る
④ 同一コンディション帯・同一付属品構成に絞る
⑤ **中央値**を採る（平均値は外れ値に歪む）
⑥ サンプル数（落札件数）を記録する
⑦ 出品者数を数える（自分が入る前の状態）
⑧ 上限仕入値 = 中央値 × 0.57 を計算して記入
```

### 4.4 ★最重要：枝番で相場が倍変わることが実証された

今回の調査で、**同じ「型番」でも枝番・付属品構成で相場が2倍以上違う**ことが
データで確認できました。**これが当社の利益の source です。**

| 型番 | 構成 | 平均落札価格 | 倍率 |
|---|---|---|---|
| HiKOKI WH36DC | 全体（セット含む） | ¥22,692 | — |
| HiKOKI WH36DC | **本体のみ** | **¥9,328** | **2.4倍差** |
| HiKOKI BSL36A18X | 通常版 | ¥11,869 | — |
| HiKOKI BSL36A18**BX** | **Bluetooth付**（末尾BX） | **¥17,503** | **1.5倍差** |
| マキタ TD173D | 本体のみ 中古（実例） | ¥15,500 | — |
| マキタ TD173D**RGX** | セット 中古（実例） | ¥31,500 | 2.0倍 |
| マキタ TD173D**RGX** | セット 未使用（実例） | ¥39,685 | 2.6倍 |

```
店頭では、この差が値札に反映されていないことがある。
「TD173D 中古 ¥12,000」の値札が、本体のみなのかセットなのかで
利益が出るか大損するかが決まる。

→ 現場では必ず「型番の末尾まで」と「付属品の現物」を確認する。
```

**`store-sourcer` は、型番の枝番を確認せずに90秒判定を通してはいけません。**

### 5.1 ⛔ 純正バッテリー単体は「保留」— 前回の推奨を撤回します

**2026/07/27 の追加調査により、BL1860B を優先度Aから外しました。**
理由は2つあり、どちらも単独で仕入停止に値します。

#### 理由1：偽造品が大量流通しており、赤線1・2に直撃する

| 事実 | 出典 |
|---|---|
| マキタ自身が「模造・非純正」バッテリへの注意喚起を公表 | [株式会社マキタ 公式](https://www.makita.co.jp/news/detail/85) |
| ヤフオク!が注意喚起。違法の疑いが強い非純正品が**中国から大量出荷** | [ITmedia NEWS](https://www.itmedia.co.jp/news/articles/2312/19/news121.html) |
| ロゴ入りの偽バッテリーは**商標権侵害**に該当 | [リツール](https://re-tool.net/82626/) |
| 模造バッテリーは**充電中に発火する可能性**がある | [voltechno](https://voltechno.com/blog/makita-2024caution/) |

```
CLAUDE.md 6.4 赤線1（真贋グレー品の出品禁止）
CLAUDE.md 6.4 赤線2（商標権侵害品の取扱い禁止）
→ 2本同時に抵触する
```

**そして最悪なのは、安い個体ほど偽物の確率が高いという構造です。**
上限仕入値 ¥6,530 以下で売られている「BL1860B」は、
まさに偽造品が紛れ込む価格帯そのものです。

さらに `law-checker` の優先順位（第8章）の①は「人の安全」です。
**発火リスクのある個体を流通させる可能性がある以上、利益の議論より前に止まります。**

#### 理由2：そもそも上限仕入値で買えない可能性が高い

買取相場（**プロの業者が買い取る価格**）が判明しました。

| 区分 | 業者の買取価格 | 出典 |
|---|---|---|
| 新品 | ¥9,000 | [ツールオフ](https://tool-off.com/market/%E3%83%9E%E3%82%AD%E3%82%BF-%E3%83%90%E3%83%83%E3%83%86%E3%83%AA%E3%83%BC-bl1860b%EF%BC%88%E6%80%A5%E9%80%9F%E5%85%85%E9%9B%BB%E5%AF%BE%E5%BF%9C%EF%BC%89) |
| **中古** | **上限 ¥5,000** | 同上 |

```
この数字が意味すること：

業者が中古を ¥5,000 上限でしか買わない
  = 業者の想定売価は ¥8,000 前後
  = **平均落札 ¥11,883 は、実勢よりかなり高い**

想定売価を ¥8,000 で引き直すと
  上限仕入値 = (8,000 × 0.9 − 800 − 100) ÷ 1.5 = **¥4,200**
  → これは業者の買取上限 ¥5,000 を下回る
  → **プロより安く買わないと成立しない**
```

**平均落札価格 ¥11,883 は、業務用まとめ売り（2個組・4個組）や
未使用品が混ざって押し上げられた数字**と考えるのが自然です。
月2,361件という異常な流動性も、互換品・模造品の大量流通で説明がつきます。

#### 理由3：電脳仕入では「買ってからしか判定できない」

真贋の判別方法は公開されています。

| 判別点 | 純正 | 模造品 | 購入前に確認できるか |
|---|---|---|---|
| **重量（BL1860B）** | 約660g | **100g以上軽い** | 店舗：△（要許可）／電脳：**×** |
| 樹脂の質感 | 黒っぽく、やや艶がある | 白っぽく、艶が少ない | 店舗：○／電脳：△（写真次第） |
| 表記 | 日本語（米国製は英語） | — | 店舗：○／電脳：△ |
| マキタロゴ | 側面・裏面にあり | ロゴなしは互換品 | 店舗：○／電脳：△ |

**電脳仕入では、決定打である重量を購入前に確認できません。**
つまり「買って、測って、偽物なら返品」という流れになります。

#### では、偽物だったとき返品できるのか（調査結果）

**販路によって答えが大きく違います。**

| 仕入先 | 偽物と判明したときの救済 | 出典 |
|---|---|---|
| **メルカリ** | **全額補償プログラムあり。**ただし**受取評価を押す前**が条件。評価後は事務局経由の返金が極めて困難 | [フリマチェッカー](https://tfp-group.co.jp/furima-checker/column/mercari-fake-refund-guide) |
| **ヤフオク! 個人出品** | **偽物は補償の対象外。**現行制度は「未着・未入金トラブルお見舞い制度」で、偽物は含まれない。**当事者同士の解決が原則** | [All About](https://allabout.co.jp/gm/gc/3202/) ／ [フリマ仙人](https://knowledge-x.com/archives/3443) |
| ヤフオク! ストア出品 | 落札後30日以内の保証が適用される場合がある | 同上 |
| 実店舗 | 店の返品規定による。購入前に現物確認できるため、そもそも問題が起きにくい | — |

```
最も危険な組み合わせ：
  ヤフオク!の個人出品から、純正バッテリーを電脳仕入する
  → 買うまで重量が測れない
  → 偽物でも補償がない
  → 自力交渉。相手が応じなければ、そのまま損失
```

#### 返品できたとしても、採算は合わない

```
往復送料 約¥1,600 ＋ 交渉・返送の作業時間 1〜2時間
→ ROI50%設計での1件あたり粗利は ¥4,000〜7,000
→ **返品1件で、成功2件分の利益が消える**
```

**「返品できるから大丈夫」は、この単価帯では成立しません。**

#### 結論：バッテリーを扱うなら「店舗仕入のみ」

| 仕入経路 | 判定 | 理由 |
|---|---|---|
| **実店舗** | **条件付きで可** | 購入前に現物を手に取って確認できる |
| メルカリ | 慎重に可 | 補償プログラムあり。ただし**受取評価を押さない運用が絶対条件** |
| **ヤフオク! 個人出品** | **不可** | 偽物の補償がなく、電脳では事前確認もできない |

##### 店舗での現実的な確認方法（秤を店頭で使えない場合）
```
① 純正の実物を1つ手元に持っておき、店頭で「持ち比べる」
   → 660g に対して 100g 差は約15%。**手で判別できる差**
② 樹脂の艶・色（純正は黒く艶がある／模造は白っぽく艶がない）
③ 側面・裏面のロゴと日本語表記
④ 相場より極端に安い個体は、それ自体が危険信号
⑤ 迷ったら買わない
```

→ `authenticity-checker` に上記の判定基準を追加しました。
**同じ理由で、HiKOKI BSL36A18X / BSL36A18BX も保留とします。**
バッテリー単体は、カテゴリごと真贋リスクが高い領域です。

```

④ 単価 ¥13,566 は目標単価帯（¥12,000〜25,000）の下限に収まる
```

**ただし WH36DC もセット品にはバッテリーが含まれます。**

#### 除外・保留の理由（データが示したこと）
```

  → アンプ・スピーカー類は当面 優先度を下げる

10・11（低単価ヘッドホン）：単価¥8,000〜9,000
  → `戦略-商材と販路.md` 1.3① のとおり、低単価はROI50%が構造的に厳しい
  → 上限仕入値 ¥4,300〜4,900 で仕入れる必要がある
```

**戦略で立てた「低単価はROI50%に向かない」「大型は送料が利益を食う」という
仮説が、実データで裏付けられました。** 商材構成は現行方針のままで正しいと判断します。
